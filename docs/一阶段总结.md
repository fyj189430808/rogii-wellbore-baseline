# 四、我认为最可能突破的四条主线

## 主线一：围绕粒子路径建立整段偏移得分图

这是当前证据最强、与现有代码距离最近的一条。

对每一行 (i)，以粒子路径 (P_i) 为中心，在偏移 (o\in[-40,40]) 或 ([-60,60]) 中构造：

[
TVT_{i,o}=P_i+o
]

然后把这一 TVT 映射到基准井 GR，计算多个尺度的匹配代价。

建议尺度至少包括：

- 原始；
- 5 英尺；
- 11 英尺；
- 21 英尺；
- 51 英尺；
- 101 英尺。

每个位置的代价不要只用一种相关性，建议包括：

- 归一化相关性；
- 经过线性缩放和平移后的绝对误差；
- 稳健中位绝对误差；
- 较大尺度的一阶变化匹配；
- 有效 GR 点比例；
- 连续有效区间长度。

然后不是逐行选择最小代价，而是联合求解：

[
\sum_i C(i,o_i)
+
\lambda_1\sum_i |o_i-o_{i-1}|
+
\lambda_2\sum_i |\Delta^2o_i|
+
\lambda_3\sum_i |o_i|
]

其中：

- 第一项是 GR 不匹配代价；
- 第二项限制偏移不能突然跳；
- 第三项限制曲率，保证偏移曲线平滑；
- 第四项使证据不足时回到原粒子路径。

最后输出：

- 最优平滑路径；
- 前向—后向平均路径；
- 偏移不确定度；
- 最优与次优路径差距；
- 缺失 GR 区间的回退标记。

这一步比继续优化逐行“最佳偏移特征”更重要。

公开的 8.8 方法自述中明确包含前向—后向平滑，这正是你们当前单向候选的关键差异。([Kaggle](https://www.kaggle.com/competitions/rogii-wellbore-geology-prediction/discussion/726465?utm_source=chatgpt.com))

## 主线三：进入“标志层归一化坐标”

不同基准井的层厚、TVT 范围和 GR 拉伸程度不同。在绝对 TVT 中直接运行粒子搜索，会把“同一地层阶段、不同厚度”的井看成不同状态。

可以把相邻标志层之间归一化：

# [ q

k+
\frac{TVT-m_k}{m_{k+1}-m_k}
]

其中 (m_k) 和 (m_{k+1}) 是相邻标志层 TVT。

这样：

- 每个标志层区间都统一到长度 1；
- 粒子状态在统一地层坐标中移动；
- 不同基准井的层厚差异被消除；
- 转移速度、曲率、GR 形状更容易跨井学习；
- 最后再根据测试基准井标志层位置变回 TVT。

你们文档中已经发现 773 个基准井文件大约只有 54 个独特模板，而且许多模板跨折。这里应当正式构造：

- 基准井平滑 GR 指纹；
- 模板编号；
- 模板出现频次；
- 标志层厚度向量；
- 模板内训练井空间分布；
- 模板专属地层曲面；
- 模板专属粒子残差先验。

测试基准井没有地质标签时，可以优先：

1. 用完整平滑 GR 指纹匹配训练模板；
2. 对高度相似模板直接转移标志层位置；
3. 对未知模板用 GR 形状检测标志层边界；
4. 保留匹配不确定度。

同时必须跑模板严格隔离验证。若按井五折提升很大、模板严格验证无提升，就说明方法主要利用比赛中的重复模板，而不是泛化到全新基准井。这在竞赛模型里未必是坏事，但必须知道收益来源。

## 主线四：预测少数几个路径残差系数，而不是预测几百万行

定义粒子路径残差：

[
r_i=TVT_i-P_i
]

你们自己的真值实验表明，残差常常能被低阶平滑函数表示。

可以令：

[
r(t)=a_0+a_1t+a_2t^2+a_3t^3
]

或使用 4～8 个平滑控制点，其中 (t) 是隐藏段归一化进度。

训练时：

1. 对每口训练井模拟真实比赛切点；
2. 重新生成粒子、束搜索、空间地层路径；
3. 在伪隐藏段拟合真实残差系数；
4. 用前缀可见信息预测这些系数。

输入可以包括：

- 着陆后前缀长度；
- 粒子与束搜索路径分歧；
- 粒子与空间地层路径分歧；
- 基准井整段匹配质量；
- 后段 GR 缺失率；
- 井斜、方位和曲率；
- 基准井模板；
- 多个晚期伪切点上的残差系数。

测试时模型只输出每口井的 3～8 个系数，再生成完整平滑路径。

这比当前逐行树模型有几个优势：

- 天然连续；
- 很难产生局部尖跳；
- 每井只有少数自由度；
- 能直接利用你们真值上限中已经证明存在的低维结构；
- 更容易做强收缩，证据不足时回退到粒子路径。

# 五、伪隐藏回测应该怎样重做

现有 F06 不建议继续堆摘要，而应从切点设计开始重做。

## 切点条件

只保留满足以下条件的切点：

- 已进入稳定近水平段；
- 井斜持续高于约 80～85 度；
- 距离着陆点已有足够长度；
- 剩余预测长度接近真实隐藏段分布；
- 切点所在标志层与真实测试起点分布相近。

每口井可以设置：

- 着陆后 250 英尺；
- 着陆后 500 英尺；
- 着陆后 1000 英尺；
- 可见近水平段的 50%、70%、90%。

但前提是这些切点确实位于近水平段，而不是按原始前缀百分比机械选择。

## 不再输出 174 个历史统计量

应直接用伪隐藏真值估计：

- 粒子、束搜索、空间路径的收缩权重；
- 粒子残差的常数、斜率和曲率；
- 各种路径随预测长度的可靠性；
- 模板专属校正；
- 前向路径与前向—后向路径之间的偏差。

然后把得到的**完整校正路径**输入最终树模型，而不是把大量回测 RMSE 常数复制到每一行。

# 六、多粒子种子仍值得补，但不能把它当成唯一答案

你们尚未在当前严格流程中复现旧版“500 粒子 × 128 个随机种子”的选择器，这是确实存在的实验缺口。

建议补跑，但输出不要是 128 条原始路径，而是：

- 前向路径均值；
- 前向路径中位数；
- 路径分位数；
- 前向—后向平滑路径；
- 多峰模式路径；
- 模式质量；
- 路径离散度；
- 与束搜索、空间地层路径的差异。

多随机种子的价值主要是：

- 减少偶然抽样误差；
- 更完整地覆盖多峰路径；
- 提供稳定的不确定性。

它不会凭空创造新的地质信息。只把 128 个种子跑得更久，而不加后向平滑、标志层坐标和空间地层先验，未必能从 12.9 直接跳到 8 以下。

# 七、还应补上的基础轨迹特征

你们 B00 有 X、Y、Z 和相对位移，却没有把井眼状态直接表达出来。

建议补充：

- 井斜；
- 带方向的方位角；
- 每 50、100、200 英尺的方位变化；
- 井眼弯曲度；
- 井眼轨迹波动；

- 是否处于造斜、着陆、稳定水平段；

- 当前井方向与地层面倾向的夹角；

公开的开源复盘也指出，带符号的方位和井眼弯曲度具有独立价值，不过单独提升通常有限。它们更适合用来控制空间地层候选和路径转移，而不是期待只靠这些表格列降低数英尺。([GitHub](https://github.com/mycarta/rogii-geosteering-toolkit))

# 八、GR 特征不应继续停留在方差和中位偏差

你们 RF02b 主要测试局部方差和中位绝对偏差，这不足以表达 GR 形状。

更合理的处理是：

1. 用可见前缀对水平井 GR 与基准井 GR 做稳健的线性缩放和平移；
2. 必要时做分位数映射；
3. 分标志层区间分别校准；
4. 去除尖峰，但保留宽尺度形状；
5. 对缺失值使用“缺失感知”平滑，不把长缺口当成真实平线；
6. 同时生成 5、11、21、51、101 英尺尺度；
7. 把这些尺度放进井深 × 偏移得分图。

你上传的样例说明，原始逐点 GR 已经有较强相关性，而平滑到几十至一百英尺后明显更强。因此细粒度一阶差分可能主要是噪声，宽尺度形状才是更稳定的层位信息。

赛事方材料也强调，水平井 GR 与基准井 GR 的分辨率可能不同，本井自相关、附近井和地质倾角都可能提供帮助。([GitHub](https://github.com/vamseeachanta/kaggle-rogii-2026/blob/main/docs/task-brief.md))

# 十、强队接近 5，最可能依靠的不是某一个神秘模型

结合公开讨论和你们已有真值上限，我认为强方法大概率是在同时做以下几件事：

1. **把地层位置归一化到标志层坐标。**
2. **使用整段隐藏 GR，而不是只做前向或逐行匹配。**
3. **通过前向—后向平滑或全局路径搜索解决重复 GR 形状。**
4. **利用附近训练井和地层曲面，生成独立的空间路径。**
5. **让粒子、束搜索、空间地层、基准井对齐形成真正互补的候选。**
6. **预测每井少量残差系数或连续候选权重。**
7. **最后才用多种树模型或序列模型组合。**

公开高分复盘中出现的也主要是受约束的曲线对齐、多尺度相关性、粒子与束搜索、空间先验、残差学习和模型组合，而不是单纯依靠更多原始表格特征。([GitHub](https://github.com/daxiongshu/competition-brief-demo/blob/main/codex_rogii-wellbore-geology-prediction_002/brief.md))

# 最后给出最明确的三项建议

接下来最值得立刻做的不是 RF04、RF05 式继续堆小统计量，而是：

### 第一项：重建同标尺验证

把 C01 在干净的按井分组五折中复现，同时保留空间隔离和模板隔离作为审计。先确认你们究竟离 8.8 有多远。

### 第二项：做合法的地层曲面路径

只用训练折地层面预测验证井地层面，再转成 TVT 路径。这是你们目前没有真正测试、但样例数据显示信号极强的方向。

### 第三项：把 F03b 彻底改成整段路径算法

以粒子路径为中心，构造井深 × 偏移得分图，用多尺度 GR 和曲率约束搜索连续偏移路径，并加入前向—后向平滑。不要再把逐行最佳偏移、峰差、熵当作主要产物。

**我的核心判断是：**

> 从 12.9 到 8～9，最可能靠验证标尺对齐、地层曲面候选和真正的双向粒子路径；从 8～9 继续向 5 靠近，则需要标志层归一化、整段全局对齐，以及每井低维残差或连续权重。单纯把 36 个特征扩充到 60 个，不足以解释这个差距。
