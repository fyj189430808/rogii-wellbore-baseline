## 缓存格式

使用 `np.savez_compressed`，但必须通过已打开的临时二进制文件写入，避免 NumPy 自动追加 `.npz` 破坏临时文件名：

```python
temporary = path.with_name(path.name + ".tmp")
with temporary.open("wb") as output_file:
    np.savez_compressed(
        output_file,
        seed_log_likelihoods=values,
        cache_fingerprint=np.asarray(fingerprint),
    )
temporary.replace(path)
```

缓存只保存 128 个累计似然和指纹；report 由 runner 另存 JSON。不得保存 target 或逐行 seed paths。
