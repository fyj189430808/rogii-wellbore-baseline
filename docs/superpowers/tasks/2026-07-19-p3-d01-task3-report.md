## 关键接口

- `load_development_registry`：先读取井级 fold 身份，再反连接 116 口影子井；正式配置下硬检查 657 口开发井及逐折行数。
- `read_legal_inputs`：水平井 CSV 只读取 `MD/Z/GR/TVT_input`，Typewell 只读取 `TVT/GR`。
- `reconcile_legacy_outputs`：按 `row_index` 对齐 8 个冻结路径字段；任何一个数值非零差异立即失败，并核对 3 个旧质量统计。
- `generate_one_well`：只有旧路径对账通过后，才保存只含 128 个累计似然和实验指纹的 NPZ。
- `load_valid_cache_hit`：同时验证 runtime 必填字段、合法列、影子/目标读取标志、NPZ schema、种子数、指纹、缓存 SHA、旧产物 SHA 和全部零差异对账结果。
- `run_legal_generation`：使用线程池逐井执行并收集井号和异常；`ensure_legal_generation_succeeded` 保证任何错误都会阻断后续阶段。
