## 1. 单井路径评分

接口：

```python
score_well_paths(target_rows: pd.DataFrame, legal_path_cache: pd.DataFrame) -> dict[str, Any]
```

`target_rows` 必须是同一井、同一 fold，并含：

```text
well_id, fold, row_index, target_tvt, pred_tvt
```

`legal_path_cache` 必须按唯一 `row_index` 含：

```text
row_index
last_visible_tvt
pf128_mean_tvt
pf128_scale_3_delta
pf128_scale_5_delta
pf128_scale_8_delta
pf128_scale_12_delta
```

严格一对一键连接，不能依赖当前行顺序。路径定义必须沿用旧 P2-P01 评分语义：

```python
p2p02 = pred_tvt
pf128_mean = pf128_mean_tvt
scale_T = float64(last_visible_tvt) + float64(pf128_scale_T_delta)
```

对每条路径保存 SSE 和 RMSE。四个固定温度中以单井 SSE 最小者作为 `oracle_best_scale`，平手按 `3,5,8,12` 顺序取第一个；保存 `oracle_scale_sse/rmse` 和 `best_scale_is_oracle=True`。oracle 字段只能存在评分结果，不能存在合法模块。

测试必须覆盖：乱序键仍得到手算结果、重复/缺键失败、非有限值失败、平手选择 3、pooled 指标基于总 SSE 而不是井 RMSE 平均。

接口：

```python
aggregate_path_metrics(per_well: pd.DataFrame) -> pd.DataFrame
```

对 `p2p02/pf128_mean/scale_3/scale_5/scale_8/scale_12/oracle_scale` 返回：总井数、总行数、SSE、pooled RMSE、macro/median/P90/worst well RMSE。oracle pooled RMSE 为各井事后最佳温度 SSE 之和，必须明确只表示上限。

## 2. 可复现 Spearman 与折方向

接口：

```python
spearman_report(frame, x_column, y_column, permutations=1000, seed=...) -> dict
correlation_tables(frame, pairs, permutations=1000, seed=...) -> tuple[pd.DataFrame, pd.DataFrame]
```

- 对 x/y 同时有限的井计算平均秩 Spearman。
- 少于 3 对或任一变量常数时明确返回 `valid=False`、rho/p 为 NaN，不要伪造 0。
- 置换只在井之间打乱 y，双侧比例为 `(1 + count(|rho_perm| >= |rho_obs|)) / (permutations + 1)`。
- 相同输入和 seed 必须逐位复现。
- `correlation_tables` 对全开发集和每个 fold 真正分别计算，不得把全表值复制到折；overall 每行保存 `same_direction_folds` 和 `valid_folds`，方向相同指非零 rho 符号相同。
- 固定 seed 要从基础 seed、pair 顺序、fold 稳定派生；不能依赖 Python 随机 hash。

测试覆盖完全单调 rho=1、确定性置换比例、五折中一折反向时方向数正确、常数列无效。

## 3. 派生诊断列、分箱和决策

接口可以自行选择清楚的名字，但至少提供：

```python
add_diagnostic_columns(per_well) -> pd.DataFrame
build_binned_metrics(per_well) -> pd.DataFrame
decide_pf_routes(per_well, overall_correlations, path_metrics) -> dict
```

固定派生定义：

```text
missing_gr_fraction = 1 - observed_gr_fraction
sigma_absolute_relative_difference = abs(gr_sigma - observed_only_gr_sigma) / max(abs(observed_only_gr_sigma), 1e-12)
scale_T_collapsed_severe = scale_T_effective_sample_size <= 2
scale_T_collapsed_medium = scale_T_effective_sample_size <= 8
scale_3_easy_oversharp = scale_3_effective_sample_size <= 2 and scale_3_rmse - min(scale_12_rmse, pf128_mean_rmse) >= 0.5
```

`build_binned_metrics` 至少按 `hidden_rows/missing_gr_fraction/longest_gr_gap_md_ft/p2p02_rmse` 各自分成确定性的四组，并对每组输出井数、行数、PF mean pooled RMSE、P2-P02 pooled RMSE、四温度 ESS 中位数以及 severe/medium collapse 比例。重复值也必须稳定，不能随机。

决策必须严格使用预登记阈值：

### PF01 支持条件（任一）

1. `missing_gr_fraction` 或 `longest_gr_gap_md_ft` 与 `pf128_mean_rmse` 的 overall `abs(rho)>=0.20` 且 `same_direction_folds>=4`；
2. 全体最高缺失四分组减最低缺失四分组的 PF mean pooled RMSE `>=0.50 ft`，且五个 fold 内至少四折同方向；
3. `sigma_absolute_relative_difference` 的井中位数 `>=0.10`。

### PF02 支持条件（两项同时）

1. 任一温度的 `scale_T_effective_sample_size` 与 `hidden_rows` 或 `observed_gr_fraction`：overall `abs(rho)>=0.25`、`same_direction_folds>=4`、置换 `p<=0.05`；
2. 最佳全局固定温度 pooled RMSE 减 oracle scale pooled RMSE `>=0.25 ft`。

返回每个子条件的数值证据、布尔值、`pf01_supported`、`pf02_supported`。若相关无效，不得通过。

注意：whole-well 累计似然只能支撑井级结论，不能由这些函数声称沿 MD 分段权重有效。
