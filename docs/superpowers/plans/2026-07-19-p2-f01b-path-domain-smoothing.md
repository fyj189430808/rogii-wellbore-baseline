# P2-F01b 实现计划

目标：只把 Typewell GR 的处理顺序改为“先沿候选 TVT 路径采样，再与水平井 GR 一起沿 MD 平滑”，验证尺度统一后连续路径是否出现真实信号。

1. 先写核心测试：非 1:1 MD/TVT 合成路径、得分面平移等变、全缺失回零和 shape 对齐；确认测试因核心文件尚不存在而失败。
2. 新建 `src/p2_f01b_path_domain_smoothing.py`。二维生成 41 条候选参考序列，按尺度流式做 MD 窗口均值，再按连续 50 ft 块向量化计算 Pearson；复用 F01 v1 的观测代价与动态规划，不修改 v1 文件。
3. 写 runner 测试：冻结配置、合法列、先落盘后评分、三种阶段门槛和缓存指纹。
4. 新建薄 runner `scripts/diagnose_p2_f01b_path_domain_smoothing.py`，支持 `smoke/fold0/all`，逐井保存并可续跑。
5. 重新运行 F01 v1 与 F01b 全部测试，确认旧实现未被改变。
6. 跑固定三井 smoke。只有程序正对照与真实前缀 real-vs-roll 检查通过，才跑 fold 0。
7. fold 0 通过预注册门槛后才跑 773 井；全量只按实验卡既定门槛判定，不调窗口、网格或约束。
8. 将事实、推断、未验证猜测、当前只能否定的实现和下一步最低成本验证写入结论、登记表、状态和路线图。
