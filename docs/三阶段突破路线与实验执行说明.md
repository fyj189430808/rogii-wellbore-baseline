# ROGII 三阶段突破路线与实验执行说明

## 一、三阶段的核心判断

当前最优基线应冻结为：

```text
P3B00_group5_p2p02_v1
```

对应二阶段的 `P2_P02_multiscale_pf_paths_v1`：

* 交叉验证：`balanced_well_5fold_v1`
* 773 口井
* 3,783,989 个自然隐藏行
* 41 个特征
* 单个 LightGBM
* 1,734 棵树
* 随机种子 29
* pooled micro RMSE：**10.305705**
* 五折：`10.1708 / 9.4625 / 9.1820 / 10.8755 / 11.6392`

其中真正的大幅提升来自 128 次粒子滤波生成的五条完整路径，而不是普通表格统计量。`pf128_mean_delta` 将 12.5392 降至 10.9345，四条似然加权路径进一步降到 10.3057，且五折均改善。([GitHub][1])

因此三阶段不应重新回到“增加几十个普通统计量”，而应围绕三个层次推进：

[
\boxed{
\text{生成更准确的 PF 路径}
\rightarrow
\text{沿井深动态选择路径}
\rightarrow
\text{预测剩余的平滑残差}
}
]

邻井、可见前缀、井眼几何和空间信息，也都应该服务于第三步——**修正当前强路径的残差**，而不是从零预测绝对 TVT。

# 二、三阶段固定合同

## 2.1 基线合同

```text
experiment_id: P3B00_group5_p2p02_v1
cv: balanced_well_5fold_v1
baseline_features: P2-P02 原 41 列
target: TVT - last_known_TVT
model: 单个 LightGBM
n_estimators: 1734
seed: 29
evaluation_rows: 自然隐藏行
```

二阶段所有候选缓存、OOF 预测和实验报告全部保留，不覆盖。

## 2.2 三阶段分为两个子阶段

### 三阶段 A：确定性路径生成

允许：

* 修改粒子滤波的观测处理；
* 重新聚合 128 条随机路径；
* 生成分段加权路径；
* 生成邻井残差校正路径；
* 使用当前井可见前缀做确定性校准；
* 新增完整路径特征。

暂不允许：

* 使用另一个模型的训练内预测；
* 输出层叠；
* 根据隐藏真值选路径；
* 对验证井使用其自身或同折井的隐藏真值。

### 三阶段 B：折外学习型残差路径

只有 A 阶段出现明确证据后，允许：

* 使用严格折外的 P2-P02 预测作为中心；
* 学习每口井少数几个平滑残差系数；
* 生成一条折外学习型修正路径。

最终仍可保持一个主 LightGBM，但必须承认这是一个严格嵌套的两级流程，不再沿用二阶段“禁止学习型轨迹”的合同。

# 三、统一实验流程

每一个新方向都按照以下顺序执行：

```text
只读诊断
   ↓
路径自身评分
   ↓
加入 P3B00 进行 folds 0–1 筛查
   ↓
通过后跑完整五折
   ↓
负对照与泄漏审计
   ↓
加入当前冠军测试条件增量
```

## 3.1 只读诊断

可以读取隐藏真值，但只能回答：

* 表示空间是否足够；
* 正确答案是否在候选范围内；
* 得分是否能识别正确路径；
* 残差是否具有低维结构。

诊断结果不得直接成为正式特征。

## 3.2 路径自身评分

每条新路径在进入 LightGBM 前，先报告：

* pooled micro RMSE；
* 五折 RMSE；
* 宏平均井 RMSE；
* 井级胜率；
* P90 井 RMSE；
* 最差井；
* 相对现有五条 PF 路径的差异；
* 路径一阶变化和二阶弯曲；
* 不同 GR 有效率、隐藏长度和困难程度切片。

一条路径单独分数一般，但与现有路径误差方向明显不同，也可以进入模型筛查；不过必须通过候选互补性诊断，不能只因为“看起来不同”就加入。

## 3.3 正式晋级门槛

### folds 0–1 筛查

[
\frac{\Delta_0+\Delta_1}{2}\ge 0.20\text{ ft}
]

并且：

[
\min(\Delta_0,\Delta_1)\ge -0.10\text{ ft}
]

其中：

[
\Delta_f=RMSE_{\rm baseline,f}-RMSE_{\rm candidate,f}
]

### 完整五折

需要同时满足：

* pooled micro RMSE 改善至少 0.10 ft；
* 至少 4/5 折改善；
* 任一折不能恶化超过 0.25 ft；
* folds 2–4 中至少 2/3 改善；
* 井级自助抽样 95% 区间上界小于 0；
* 总体井级胜率至少 55%；
* P90 井 RMSE 恶化不超过 0.20 ft；
* 收益最大的前 5% 井不能贡献超过总正收益的 60%。

# 四、P3-D00：当前 10.3 剩余误差结构审计

这是所有正式实验前最应该先完成的一步。

## 4.1 目的

回答当前剩余误差主要属于哪一类：

1. 整口井整体偏高或偏低；
2. 随井深持续倾斜；
3. 轻微弯曲；
4. 中途开始走错；
5. 高频局部抖动；
6. 少数井灾难性错层。

定义 P2-P02 折外残差：

[
e_i=TVT_i^{true}-TVT_i^{P2P02}
]

每口井分别拟合：

### 常数残差

[
e(t)=a_0
]

### 一次残差

[
e(t)=a_0+a_1t
]

### 二次残差

[
e(t)=a_0+a_1t+a_2t^2
]

### 三次残差

[
e(t)=a_0+a_1t+a_2t^2+a_3t^3
]

以及：

* 4 个平滑控制点；
* 8 个平滑控制点；
* 强制 (e(0)=0) 的锚定版本；
* 不强制锚定的版本。

## 4.2 必须输出

| 指标             | 作用            |
| -------------- | ------------- |
| 原 P2-P02 RMSE  | 10.3057 基线    |
| 常数修正 oracle    | 判断整体偏差占比      |
| 一次曲线 oracle    | 判断长期倾斜占比      |
| 二次/三次 oracle   | 判断曲率占比        |
| 4/8 控制点 oracle | 判断低维平滑表示上限    |
| 高频残差 RMSE      | 判断剩余是否主要是局部噪声 |
| 各项 SSE 占比      | 决定后续资源分配      |

一阶段已经发现旧 PF 残差用三次曲线拟合可以到约 4.24，当前候选线性组合的真值表示上限约为 3.5；但这些数字必须在新的 P2-P02 OOF 残差上重算。

## 4.3 决策规则

如果 P2-P02 残差满足：

* 一次曲线 oracle 已低于 7；
* 二次或三次曲线 oracle 低于 5～6；

则说明三阶段最重要的任务是预测少数几个残差系数。

如果即使 8 个控制点仍高于 8，则说明当前剩余误差主要是分支错选，应该优先加强路径模式和 GR 选择，而不是立即做低阶残差学习。

# 五、P3-D01：PF 观测证据与随机路径权重审计

## 5.1 为什么优先审计这里

当前 PF 代码有三个非常重要的行为：

1. 可见前缀缺失 GR 被填成 0，再用于估计 `gr_sigma`；
2. 隐藏段 GR 先进行双向线性插值，插值结果和真实观测一样进入粒子权重更新；
3. 128 条路径的最终权重来自整条隐藏段累计对数似然，再除以固定的 3、5、8、12 温度。([GitHub][2])

当前加权公式是：

[
w_s(T)=
\frac{\exp((L_s-\max L)/T)}
{\sum_r\exp((L_r-\max L)/T)}
]

其中 (L_s) 是第 (s) 个随机种子的整井累计似然。([GitHub][2])

这意味着固定温度可能同时受以下因素影响：

* 隐藏段长度；
* 真实观测 GR 数量；
* 插值行数量；
* 最长缺口；
* 估计的 GR 噪声；
* 不同井的似然绝对尺度。

## 5.2 审计输出

每口井、每个温度至少记录：

```text
hidden_rows
observed_gr_rows
interpolated_gr_rows
observed_gr_fraction
longest_gr_gap
effective_observation_count

gr_sigma
affine_gr_intercept
affine_gr_slope

seed_ll_mean
seed_ll_std
seed_ll_range
ll_per_observed_row

scale_3_ess
scale_5_ess
scale_8_ess
scale_12_ess

scale_*_max_weight
scale_*_entropy
```

有效路径数定义为：

[
K_{\rm eff}
===========

\frac{1}{\sum_s w_s^2}
]

同时分析：

* 有效路径数与隐藏长度的关系；
* 有效路径数与 GR 有效率的关系；
* 有效路径数与 P2-P02 误差的关系；
* 最优温度与井长、GR 缺失率的关系；
* 困难井是否普遍出现权重塌缩；
* 容易井是否被过度尖锐的权重带偏。

这一步只做分析，不生成正式特征。

# 六、P3-PF01：缺失感知、稳健校准的多随机种子 PF

这是三阶段第一项正式实验，也是我认为成功概率最高的一项。

## 6.1 核心假设

当前 PF 将长缺口中的线性插值点当成大量独立观测，可能人为强化错误路径；可见 GR 缺失填 0 也可能污染观测噪声估计。

新的观测更新应改为：

[
w_{p,i}^{new}
=============

w_{p,i}^{old}
\cdot
L_{p,i}^{q_i}
]

其中：

[
q_i=
\begin{cases}
1, & \text{真实观测 GR}\
q_{\rm interp}, & \text{插值得到 GR}\
0, & \text{完全缺失}
\end{cases}
]

若 (q_i=0)，粒子继续按运动模型传播，但不做 GR 权重更新，也不因该行触发重采样。

## 6.2 固定三个版本

不要搜索十几组参数，只预登记三个版本。

### PF01-A：只用真实 GR

```text
真实观测 GR 权重 = 1
插值 GR 权重 = 0
```

其余 PF 参数全部冻结。

### PF01-B：真实 GR + 稳健校准

在可见前缀拟合：

[
GR_h=a+b,GR_t+\epsilon
]

只使用真实观测点，以稳健方法估计 (a,b)，然后用中位绝对偏差估计：

[
\sigma_{GR}
===========

1.4826\cdot median(|\epsilon-median(\epsilon)|)
]

再限制在当前合法上下界内。

### PF01-C：插值点作为弱证据

```text
真实观测 GR 权重 = 1
插值 GR 权重 = 0.25
```

同时使用 B 版的稳健校准和稳健噪声估计。

## 6.3 选择规则

先在 folds 0–1 上只比较新 PF 路径自身，不训练 LightGBM。

按照以下顺序选择：

1. 两折 pooled 路径 RMSE；
2. 井级胜率；
3. P90；
4. 困难井和容易井是否同时稳定；
5. 负对照是否明显变差。

只选一个版本进入五折正式模型，不把三个版本全部塞入模型。

## 6.4 正式输出

建议第一版输出五条完整路径：

```text
pf128_obs_mean_delta
pf128_obs_scale_3_delta
pf128_obs_scale_5_delta
pf128_obs_scale_8_delta
pf128_obs_scale_12_delta
```

先作为一个完整特征组加入 P3B00，不加入几十个质量统计量。

如果路径组晋级，再单独测试：

```text
observed_gr_fraction
effective_observation_count
longest_gr_gap
robust_gr_sigma
```

作为一个独立的小可靠性组。

## 6.5 负对照

必须至少做一个：

* 井内循环错移真实观测掩码；
* 或随机将真实 GR 行改成弱证据行。

正式版本必须显著优于负对照。

# 七、P3-PF02：按有效路径数生成权重路径

## 7.1 核心问题

当前固定温度 3、5、8、12 在每口井上可能表示完全不同的选择强度：

* 某口井 `scale=12` 仍然只剩一条路径；
* 另一口井 `scale=3` 还保留几十条路径。

因此不再固定温度，而是固定**有效路径数**。

## 7.2 方法

对于每口井，根据 128 条随机路径的似然，求一个温度 (T)，使：

[
K_{\rm eff}(T)
==============

\frac{1}{\sum_s w_s(T)^2}
]

接近预先设定的目标。

建议固定：

```text
目标有效路径数 = 2 / 8 / 32 / 96
```

通过二分搜索温度求解，不使用隐藏真值。

生成：

```text
pf128_ess2_delta
pf128_ess8_delta
pf128_ess32_delta
pf128_ess96_delta
```

## 7.3 为什么可能优于固定温度

这些路径在所有井上的含义更统一：

* ESS 2：接近最优少数路径；
* ESS 8：较尖锐选择；
* ESS 32：中等平均；
* ESS 96：接近广泛平均。

不会因为井长不同而使同一参数含义漂移。

## 7.4 正式实验

先使用 PF01 选出的观测处理方式重新生成 128 条路径，然后：

1. 路径自身评分；
2. 与现有 scale 3/5/8/12 做相关性和差异分析；
3. 加入 P3B00；
4. 加入 PF01 晋级冠军，测试条件增量。

第一版只加入四条路径，不把有效路径数和熵一起混进来。

# 八、P3-PF03：分段似然加权路径

这是最有希望形成第二次数英尺级结构突破的方向之一。

## 8.1 当前方法的限制

目前一口井从隐藏段开始到结束都使用同一套 128 随机种子权重。

但真实情况可能是：

* 前 1000 ft 更像路径 A；
* 中段更像路径 B；
* 后段更像路径 C。

全井固定权重无法表示这种变化。

## 8.2 第一版：局部软加权

将隐藏段按重叠窗口计算局部似然。

建议固定三个窗口：

```text
250 ft
500 ft
1000 ft
```

窗口中心每 100 ft 移动一次。

对窗口 (b)、随机路径 (s)：

[
L_{s,b}
=======

\sum_{i\in b}
q_i
\log p(GR_i\mid P_s(i))
]

在每个窗口中按目标有效路径数，例如 ESS=16，生成权重：

[
w_{s,b}
=======

softmax(L_{s,b}/T_b)
]

然后对 (\log w_{s,b}) 沿井深做平滑，再归一化：

[
\widehat P(i)
=============

\sum_s w_s(i)P_s(i)
]

这样权重可以缓慢变化，但不会逐行剧烈跳动。

## 8.3 输出

```text
pf128_local250_delta
pf128_local500_delta
pf128_local1000_delta
```

以及可选的一条共识路径：

```text
pf128_local_consensus_delta
```

第一轮模型只加入完整路径。

局部有效路径数、局部分歧和权重变化速度在路径晋级后再单独测试。

## 8.4 平滑和连续性检查

必须报告：

* 偏移一阶变化 P90；
* 二阶弯曲 P90；
* 每口井最大局部跳变；
* 权重模式切换次数；
* GR 长缺口中路径是否自动回到全局均值路径。

## 8.5 负对照

至少包括：

* 当前井 GR 井内循环错移；
* GR 顺序反转；
* 局部窗口权重随机打乱但保持井级分布。

真实局部权重路径必须明显优于这些负对照。

# 九、P3-MODE01：提取 128 条路径的多峰结构

二阶段 P03 只加入逐行随机种子标准差，两折仅改善约 0.019 ft，置信区间跨零；但这只说明“无方向标准差”没用，并不能否定多峰结构。([GitHub][3])

## 9.1 为什么标准差不够

同样的标准差可能对应：

* 上下两个对称模式；
* 大多数路径在下方、少量路径远在上方；
* 前半段一致、后半段分叉；
* 三个独立路径模式。

这些情况需要的修正方向完全不同。

## 9.2 路径聚类

每条随机路径在隐藏段归一化进度上采样 64 个点：

[
x_s=
[P_s(t_1),P_s(t_2),\dots,P_s(t_{64})]
]

减去均值路径后，固定聚成 3 个模式。

建议使用确定性层次聚类或固定随机种子的聚类，不根据真值选择聚类数。

对每个模式输出：

* 模式中心完整路径；
* 模式总似然质量；
* 模式包含的随机种子比例；
* 模式内离散程度；
* 第一、第二模式分叉位置；
* 第一、第二模式终点差。

## 9.3 正式特征组

```text
pf_mode1_delta
pf_mode2_delta
pf_mode3_delta
pf_mode1_mass
pf_mode2_mass
pf_mode12_margin
pf_mode12_separation
pf_mode_split_fraction
```

其中最重要的是三条模式中心路径。

## 9.4 通过标准

至少满足一个条件才进入正式模型：

* 某条模式中心路径自身优于现有最佳 PF 路径；
* 每井最佳模式 oracle 明显优于现有五条路径；
* 模式分叉方向能够稳定区分 P2-P02 的正、负残差；
* 模式结构在随机取一半种子时仍稳定。

# 十、P3-GR01：以强路径为中心的小范围 GR 残差路径

二阶段连续 GR 路径失败，并不是 GR 完全没信息。真实 GR 比循环打乱负对照好约 1.68 ft，但正确偏移的中位排名只有第 18，前五命中率约 20.73%，说明当时的绝对位置评分仍被重复 GR 形状误导。([GitHub][3])

新版本不能再原样搜索 ±40 ft。

## 10.1 先做覆盖审计

围绕新的最佳确定性 PF 路径，计算：

[
o_i^{true}
==========

TVT_i^{true}-TVT_i^{center}
]

报告：

* 真值落在 ±10 ft 的比例；
* 真值落在 ±20 ft 的比例；
* 真值落在 ±30 ft 的比例；
* 分块真实偏移的平滑程度；
* 各范围的理论网格 oracle。

如果 ±20 ft 覆盖不足 85%～90%，说明中心仍不够强，应先完成 PF03 或 MODE01。

## 10.2 得分图

第一版只搜索：

```text
offset = [-20, 20] ft
step = 1 或 2 ft
```

使用：

* 11 ft 平滑 GR；
* 31 或 51 ft 平滑 GR；
* 101 ft 平滑 GR；
* 局部稳健线性校准后的绝对误差；
* 一阶形状变化误差；
* 多尺度偏移一致性；
* 真实观测 GR 支持度。

不要只使用 Pearson 相关系数。

## 10.3 审计通过标准

相比二阶段 F01b，至少达到：

* 真实偏移块级中位排名不高于第 10；
* 前五命中率达到约 40% 或以上；
* 真实 GR 明显优于循环错移负对照；
* 得分最优偏移的方向与真实残差方向存在稳定关系。

若达不到，停止，不进入动态规划。

## 10.4 整段路径

通过后求解：

[
\sum_i C(i,o_i)
+
\lambda_1\sum_i|o_i-o_{i-1}|
+
\lambda_2\sum_i|\Delta^2o_i|
+
\lambda_3\sum_i|o_i|
]

输出：

```text
gr_corrected_pf_delta
gr_smooth_offset
gr_path_support
gr_path_margin
```

第一轮正式模型只加入校正路径和偏移路径。

## 10.5 两种中心必须区分

### GR01-A：确定性 PF 中心

使用 PF128 路径，不涉及输出层叠，优先执行。

### GR01-B：P2-P02 模型中心

训练井必须使用 P2-P02 的 OOF 预测；测试井使用全训练模型预测。它属于学习型两阶段流程，只能在三阶段 B 执行，绝不能用训练内拟合预测构造训练特征。

# 十一、P3-H01：近水平段伪隐藏校准与容易井回退

多随机种子 PF 的主要收益偏向原本困难的井，而部分容易井出现过度修正。因此需要一种只利用当前井可见前缀的合法回退机制。

## 11.1 正确的伪隐藏设计

不能再按可见前缀 50%、65%、75% 机械切分。

只选择满足以下条件的切点：

* 已进入稳定近水平段；
* 由 (X,Y,Z,MD) 推导的井斜足够高；
* 切点前至少有一定水平段长度；
* 切点后仍有 250、500 或 1000 ft 可见 TVT；
* 模拟隐藏时只遮蔽 TVT_input，切点后的 GR 仍然可见。

这才符合比赛测试状态。

## 11.2 每个伪切点重新生成候选

至少重新生成：

* `pf128_mean_delta`
* 四条全局加权 PF 路径；
* PF01/PF02/PF03 晋级路径；
* 一条较保守基准路径。

在伪隐藏真值上估计：

* 哪类路径更稳定；
* P02 是否过度修正；
* 常数残差；
* 残差斜率；
* 残差曲率；
* 最佳收缩系数。

## 11.3 收缩路径

定义保守路径 (P_{safe}) 和当前强路径 (P_{strong})：

[
P_{\alpha}
==========

P_{safe}
+
\alpha(P_{strong}-P_{safe})
]

其中：

[
\alpha\in[0,1]
]

根据多个伪切点表现确定 (\alpha)，并向默认值强收缩，避免一个短伪隐藏结果决定整井。

正式输出：

```text
prefix_calibrated_delta
prefix_shrinkage_alpha
prefix_calibration_stability
```

不要再输出 174 个历史统计量。

# 十二、P3-N01：严格折外邻井残差曲线

## 12.1 结论

在新的按井五折下，邻井路线值得升为高优先级。

原因是该验证只保证整口井不跨折，并不再把 1000 距离内的空间连通井整体放在同一折；因此验证井附近可能存在训练井。([GitHub][3])

但旧空间实验已经说明：

> 邻井或空间信息不适合从零恢复目标井的绝对 TVT 路径。

正确目标应改为：

[
\boxed{\text{邻井预测当前 PF 路径的低频残差}}
]

二阶段几种空间绝对路径没有形成可用独立路径，这只否定了当时的绝对路径表示，并未否定空间残差。([GitHub][1])

## 12.2 第一版基准残差

优先使用一条确定性、无需训练的 PF 路径：

[
r_j(t)
======

TVT_j^{true}(t)-TVT_j^{PF}(t)
]

不要一开始就用 P2-P02 模型残差，否则会立即引入嵌套 OOF 问题。

把每口源井的残差拟合成：

[
r_j(t)
======

a_{j0}+a_{j1}t+a_{j2}t^2+a_{j3}t^3
]

或者 4～6 个平滑控制点。

## 12.3 邻井选择

距离不能只用井口或中点，应至少包含：

* 两条完整轨迹的最近 XY 距离；
* 中位最近距离；
* 带方向方位差；
* 平行重叠长度；
* 顺井方向距离；
* 横向距离；
* heel/toe 相对位置；
* Typewell 指纹是否相同或相近。

第一版采用严格筛选：

```text
方位差较小
平行重叠足够长
轨迹距离小于固定阈值
```

## 12.4 残差聚合

对目标井：

[
\widehat a_k
============

\frac{\sum_j w_j a_{jk}}
{\sum_j w_j}
]

权重由以下因素决定：

[
w_j
===

w_{\rm distance}
\cdot
w_{\rm direction}
\cdot
w_{\rm overlap}
\cdot
w_{\rm typewell}
]

再加支持度收缩：

[
\eta
====

\frac{\sum_jw_j}{\sum_jw_j+\kappa}
]

最终：

[
\widehat r(t)
=============

\eta
\sum_k\widehat a_k t^k
]

[
P_{\rm neighbor}(t)
===================

P_{\rm PF}(t)+\widehat r(t)
]

邻居不足时自然回到原 PF。

## 12.5 正式特征

```text
neighbor_corrected_delta
neighbor_residual_bias
neighbor_residual_slope
neighbor_residual_curvature
neighbor_endpoint_residual
neighbor_support_count
neighbor_effective_weight
neighbor_mean_distance
neighbor_residual_disagreement
```

最重要的是第一列完整路径。

## 12.6 严格数据血缘

对外层验证 fold (v)：

1. 残差源井只能来自其他四折；
2. 验证折任何隐藏 TVT 都不能进入邻井表；
3. 给训练井构造特征时必须排除该井自身；
4. 训练特征也不能使用验证折井作为邻居；
5. 每个 outer fold 都要生成独立缓存。

也就是说，不能预先生成一个“全数据 leave-one-well-out 邻井缓存”，然后五折共用，因为其中训练行的邻井特征可能已经使用了当前验证折标签。

## 12.7 先做空间信号审计

正式模型前先检查：

* 邻井残差系数差异是否随距离增大；
* 相似方向井是否比垂直方向井更相似；
* 相同 Typewell 模板是否更相似；
* 真邻居是否优于随机邻居；
* 邻井校正路径是否优于打乱残差系数的负对照。

如果邻井残差没有明显空间相关性，立即停止。

## 12.8 必须双重报告

邻井实验必须同时报告：

1. `balanced_well_5fold_v1` 主分数；
2. `spatial_pad_1000_v1` 压力测试；
3. 不同最近邻距离分层；
4. 有近邻与无近邻井；
5. 同模板与不同模板井。

若按井五折提升而空间隔离下降，应明确解释为：

> 比赛式空间内插信号，而不是全新区域外推能力。

# 十四、P3-R01：低维平滑残差学习

这是冲击 8.x 甚至更低的高潜力路线，也是三阶段最重要的结构升级。

## 14.1 表示

令：

[
U=TVT+Z
]

当前强路径：

[
U^{base}=TVT^{base}+Z
]

学习：

[
r(t)=U^{true}(t)-U^{base}(t)
]

由于两边加同一个 Z，它与 TVT 残差相同，但在结构解释上更自然。

使用 4～6 个固定平滑基函数：

[
r(t)=\sum_{k=1}^{K}a_kB_k(t)
]

建议强制：

[
r(0)=0
]

或者加入一个受强正则约束的起点偏差。

## 14.2 系数预测输入

每口井只生成一行井级输入，包括：

* PF128 模式质量；
* 全局和局部有效路径数；
* 不同 PF 路径的终点差；
* 分叉位置；
* PF 与 Beam 带符号分歧；
* 真实 GR 有效率和最长缺口；
* 可见前缀 U 坡度；
* P2 路径初段坡度；
* 二者斜率和曲率断点；
* 井斜、方位和弯曲度；
* 伪隐藏校准结果；
* 邻井预测的残差系数；
* Typewell 指纹和匹配质量。

不要把数百万逐行样本直接用于系数模型。系数模型的数据单位是 773 口井，因此应采用强正则的简单模型，例如：

* 多输出岭回归；
* 稳健线性回归；
* 小型 LightGBM；
* 每个系数一个低复杂度模型。

## 14.3 严格嵌套

对每个 outer fold：

1. 计算 outer-train 井的残差系数目标；
2. 只用 outer-train 井训练系数模型；
3. 预测 outer-valid 井的系数；
4. 生成 outer-valid 修正路径；
5. 直接评分该路径；
6. 再决定是否将该路径作为主 LightGBM 的一列特征。

不能先用全 773 口井拟合系数模型，再报告五折。

## 14.4 正式评价顺序

先评价：

[
TVT^{base}+\widehat r(t)
]

这条路径自身的 OOF RMSE。

若路径自身稳定改善，再测试：

```text
P3 champion features
+ learned_residual_delta
```

不应一开始同时训练一个复杂的第二阶段主模型，否则很难判断收益来自哪里。

旧前缀坡度失败的主要原因是将短期坡度无界外推数千英尺。

新版本不外推绝对轨迹，而只检查当前强路径与可见端是否连续。

# 十九、独立路线不能完全串行绑死

每个主要信息源都应有两个实验：

### 边际价值

```text
P3B00 + 新特征组
```

回答：

> 该信息源本身是否有效？

### 条件增量

```text
当前冠军 + 新特征组
```

回答：

> 在已有强路径之后，它还有没有新增价值？

例如邻井路线即使加到 PF03 后只改善 0.05，也可能单独加到 P3B00 改善 0.8。不能因此说邻井没信息，只能说它和 PF03 重复。

同样，PF03 失败也不应阻止 N01、H01 或 R01。

* XY 空间网格；
* 方位；
* Typewell 指纹。

命名：

# 最终建议

最先实施以下四项：

## 第一项：P3-D00

重新计算当前 P2-P02 残差的常数、一次、二次、三次和控制点 oracle。

它会告诉你们：

> 当前 10.3 到底是“路径模式仍选错”，还是“路径基本正确但有平滑残差”。

## 第二项：P3-D01 + P3-PF01

审计真实 GR、插值 GR、有效路径数和井长之间的关系，然后重做缺失感知、稳健校准的 128-seed PF。

这是距离现有代码最近、成功概率最高的一步。

## 第三项：P3-PF02 + P3-PF03

将固定温度改成固定有效路径数，再允许路径权重沿井深缓慢变化。

当前二阶段已经证明“多条完整 PF 路径”是大信号，分段加权是对这一主线最自然的继续推进。

## 第四项：P3-N01

在当前按井五折下，严格 outer-fold 地使用邻井预测确定性 PF 的低频残差，而不是预测绝对 TVT。

这是 CV 改变后最值得重新打开的一阶段信息源。

整体上，三阶段最合理的目标不是立即从 10.3 宣称冲到 5，而是：

[
10.3
\rightarrow
9.x
\quad\text{依靠 PF 观测和路径选择改进}
]

随后：

[
9.x
\rightarrow
8.x\text{ 或更低}
\quad\text{依靠分段路径、多峰结构、邻井残差和低维残差学习}
]

真正冲向 5 附近，则大概率必须进入严格折外的学习型连续残差路径；只在当前 41 列基础上继续增加普通统计特征，很难跨越这个表示瓶颈。
