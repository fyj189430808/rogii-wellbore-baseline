# P4_FINAL00_UP03_v1：一次性影子验证实验卡

登记时间：2026-07-20

## 唯一假设

开发集上已经独立确认的整井平滑先验与保守粒子修正能够泛化到从未查看过目标或误差的 116 口影子井。

## 唯一候选

```text
P4_FINAL00_UP03_v1 = UP03

基础路径：P2-P02 / P3B00
UP01：对 U=TVT+Z 做二次稳健投影，固定融合 0.50
PFS：固定 lag 1000 ft，修正比例固定 0.25
最终：UP01 + 0.25 * (PFS_lag1000_abs - P3B00)
```

禁止增加井级门控、每井 alpha、额外模型或新参数。影子集上不比较 UP01、UP02、UP08，也不搜索融合比例。

## 血缘与读取顺序

1. 从冻结的 `P3_shadow_holdout_v1` 取得 116 个井号，不读取目标或误差。
2. 只读取 P2-P02 OOF 的预测列、MD、折号，读取合法的 Z/GR/TVT_input/Typewell。
3. 生成 PFS、UP01 和最终 UP03 路径，先保存候选、配置、文件哈希和 `hidden_target_read=false` 清单。
4. 合法候选全部落盘后，首次读取这 116 口井的隐藏 `target_tvt`。
5. 只评分 P3B00 与冻结 UP03；评分后影子集永久标记为已打开，不得再用于选择参数或路线。

## 一次性通过门槛

- pooled micro RMSE 至少改善 `0.15 ft`；
- 五个影子折中至少 `3/5` 改善；
- 逐井胜率至少 `52%`；
- 逐井配对 bootstrap 的 95% 区间上界不高于 `0`；
- P90 well RMSE 相对 P3B00 恶化不超过 `0.20 ft`。

只有全部满足，证据等级才登记为 `shadow_confirmed`。改善 `0.05–0.15 ft` 只能登记为小幅正收益，不能用影子集调参；恶化则关闭当前 UP03 平滑组合路线。

## 同时预登记的严格版本

标准评分与严格评分在影子目标打开前同时登记，两者都必须完成，不能看完标准结果再决定是否运行严格版本。

对每个影子子折 `f`：只用不属于影子集且 `fold != f` 的开发井训练冻结的 P2-P02，预测属于 `fold == f` 的影子井，再施加完全相同的 UP03。严格版本不得改变任何特征、树数、种子、投影或粒子修正参数。

标准与严格评分分别应用同一门槛；只有两者都通过，最终证据才登记为 `shadow_confirmed_pipeline`。任一失败都必须原样记录，不能用影子结果调参。

## 一次性影子结果（2026-07-20，已完成）

### 数据直接证明的事实

标准影子评分中，P3B00 为 `10.492112`，冻结 UP03 为 `10.097720`，改善 `0.394391 ft`；5/5 折改善，胜井率 `76.72%`，井级 bootstrap 95% 区间为 `[-0.775354, -0.090905]`，P90 恶化 `0.154127 ft`，全部门槛通过。

严格影子评分中，严格重训基线为 `10.956707`，冻结 UP03 为 `10.353233`，改善 `0.603474 ft`；5/5 折改善，胜井率 `72.41%`，井级 bootstrap 95% 区间为 `[-1.116237, -0.218192]`，P90 改善 `0.247172 ft`，全部门槛通过。

标准与严格合同同时通过，最终 `result_class` 为 `shadow_confirmed_pipeline`。

### 基于事实的合理推断

固定的整井 U 投影和保守 PFS 修正并非只适配反复使用的 657 口开发井，在没有参与候选选择的影子井上仍有稳定增量。

### 仍然没有验证的猜测

收益能否等比例迁移到 Kaggle 测试集和 private LB 尚未验证；影子成绩不是榜单成绩。

### 当前实验只能证明的范围

结果只确认冻结的“二次投影 0.50 + lag1000 PFS 修正 0.25”组合，不能推广为其他平滑窗口、比例或逐井门控同样有效。

### 下一步最便宜的验证

不再调整这条管线的参数，生成与影子流程完全同构的测试预测，并同时保留原始 P2-P02 与最终 UP03 两份提交文件。影子集自此永久锁定。
