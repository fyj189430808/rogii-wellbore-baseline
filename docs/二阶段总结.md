# ROGII 二阶段实验总结

> 主验证：`balanced_well_5fold_v1`  
> 验证单位：完整井  
> 固定模型：单个 LightGBM，1,734 棵树，seed 29  
> 评价范围：773 口井、3,783,989 个自然隐藏行

## 1. 最终结果

二阶段当前登记路线已经全部运行，或按照实验卡中的预注册门槛停止。

最终最佳是 `P2_P02_multiscale_pf_paths_v1`：

```text
micro RMSE = 10.3057049921
fold 0 = 10.1707966874
fold 1 =  9.4624641719
fold 2 =  9.1819737877
fold 3 = 10.8754729398
fold 4 = 11.6391966763
P90 well RMSE = 14.3605402076
```

对照：

```text
carry-forward = 15.9098528707
P2B00          = 12.5392278237
P2-P01         = 10.9345371996
P2-P02         = 10.3057049921
```

因此 P2-P02 相对 P2B00 改善 `2.2335228317 ft`，相对 carry-forward 改善 `5.6041478787 ft`。

## 2. 本阶段真正有效的变化

### P2-P01：128 个固定随机种子的 PF 均值完整路径

只在 C01 36 列上增加 `pf128_mean_delta` 一列，完整五折从 `12.5392278` 降到 `10.9345372`，五折全部改善。它说明单次 PF 的随机漂移很大，多随机种子的整段均值路径提供了强而稳定的信息。

### P2-P02：四条固定尺度 PF 完整路径

只增加 scale 3、5、8、12 四条完整路径，完整五折进一步降到 `10.3057050`，五折全部改善。井内反转四条路径后 fold 0 明显变差，说明收益不只是每井数值分布，而包含路径在井深方向上的位置和顺序信息。

这两项共同支持《一阶段总结》的核心判断：问题首先是完整路径恢复和表示，不是普通逐行表格缺失值回归。

## 3. 已完成但当前实现没有得到支持的路线

- P2-D01：50/100 ft 独立局部 GR offset 打分不能稳定识别真实 offset。
- P2-S01/S02/S03：三种严格 outer-fold 空间地层路径表示均未形成可用独立路径。
- P2-F01/F01b：当前 Pearson-NCC 得分面加连续动态路径仍偏爱错误 GR 别名分支。
- P2-M01：六个大 marker 区间太宽，不能改善当前候选排名。
- P2-P03：原始逐行 `pf128_seed_std` 在 P2-P02 上只有 `0.0186 ft` 两折改善，bootstrap 跨 0，按门槛停止。

这些结果只否定各自的具体实现，不否定 GR、surface、marker、空间邻井或 PF 不确定性信息源。

## 4. 关于“同井覆盖”

本项目中的“同井覆盖”只指利用公榜测试井能在训练集中找到同一口物理井的数据漏洞。它不等于当前井可见前缀覆盖部分 TVT，也不等于附近存在训练井。

二阶段正式最佳 P2-P02 只使用当前井合法输入、对应 Typewell、冻结 PF/Beam 候选和固定单模 LightGBM，没有使用该公榜同井漏洞。

## 5. 证据边界

- 主结果来自按完整井五折，不再与一阶段 `spatial_pad_1000_v1` 的 `12.9307` 直接判优劣。
- P2-P01/P02 是在开发过程中根据前一实验结果继续提出，不是 untouched holdout。
- 当前最佳仍是逐行 LightGBM 使用完整路径特征，尚不能说已经解决了全局连续路径恢复。
- 强队低于 5 的说法没有统一、可复现的相同 CV 协议，不能直接当作本项目的可比目标值。

## 6. 当前路线为何在这里结束

根 `AGENTS.md` 指定的二阶段权威清单是 `phase2_roadmap.md`。旧 `feature_roadmap_v2.md` 使用一阶段空间 CV，已经被二阶段按井五折协议取代，不需要重新逐项跑一遍。

P2-P03 是 `current_state.json` 中最后一个明确登记的待做实验。它已经按门槛完成并停止，因此当前路线没有剩余登记实验。

“二阶段完成”表示当前路线执行完，不表示所有研究方向永久结束。下一阶段若继续，应重新冻结路线，优先研究：

1. 把整条 PF/Beam 残差压成少数平滑系数；
2. 128 seed 的分位宽度、多峰和分歧增长，而不是单个标准差；
3. 更细 marker 坐标或模板专属全局配准；
4. 能表示“路径朝哪个方向错、从哪里开始错”的连续修正。
