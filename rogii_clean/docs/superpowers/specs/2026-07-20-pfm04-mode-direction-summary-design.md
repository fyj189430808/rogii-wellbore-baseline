# PFM04 模式方向摘要设计

## 目标

在 `P3B00 / P2-P02` 原 41 个特征上，只增加三个测试时合法的井级摘要：

- `direction_score`
- `p2_position_raw`
- `high_minus_low_separation`

主模型、树数、随机种子、折分和评价行全部冻结。

## 选择依据

657 口开发井的只读审计显示，前两个特征对井级平均残差方向具有弱但五折同向的信号；第三个特征主要识别“P2 已基本正确”的中间类。信号不足以直接修改路径，只适合交给现有 LightGBM 做强收缩。

## 数据流

1. 读取已冻结的 PF128 逐井 seed 路径和最终似然。
2. 调用 `src/p3_pfm01_ordered_pf_modes.py` 的现有确定性三模式逻辑。
3. 在读取隐藏真值前，只保存上述三个井级数值、自然井号、fold 和完整来源指纹。
4. CV runner 按 `well_id` 把三个数值重复到该井全部隐藏行。
5. 原 41 列与 3 个新特征组成 44 列，训练冻结的单模 LightGBM。

## 固定合同

- 不加入 low/middle/high 三条逐行路径。
- 不加入 mode mass、末端分离度或旋转负对照。
- 不训练独立分类器或残差模型。
- LightGBM 固定 1734 棵树、seed 29，其余配置与 P3B00 完全一致。
- 先运行 folds 1–2；平均改善至少 0.15 ft，且任一折恶化不得超过 0.15 ft，才运行 folds 3–4。
- folds 1–2 已用于只读方向审计，因此只作为开发筛查；folds 3–4 才是未查看确认折。

## 失败含义

失败只否定“这三个井级 PF 模式摘要作为冻结 LightGBM 直接特征”的实现，不否定 PF128 候选路径或其他严格嵌套分类方式。
