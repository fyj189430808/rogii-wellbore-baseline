# P3-PF02 实验卡：固定有效路径数的整井加权路径

- 实验编号：`P3_PF02_target_ess_paths_v1`
- 唯一假设：固定温度在不同井上代表不同选择强度；把权重温度逐井调到相同目标 ESS，可能得到语义更统一的路径。
- 与基线唯一不同之处：种子路径的最终整井聚合方式。旧 GR 处理、旧 sigma、PF 状态转移、500 粒子、128 随机种子、CV、评价行和模型都冻结。
- 预登记目标：`ESS = 2 / 8 / 32 / 96`，一次 PF 回放后用二分温度生成四条 `delta`。
- 合法输入：当前井可见数据、Typewell、128 条冻结规则生成的种子路径及其累计似然。
- 硬核对：本次 128 个种子 LL 必须与 D01 NPZ 逐位完全一致，否则该井失败且不评分。
- smoke：固定第一口开发井；folds 0～1 通过后才允许 folds 2～4。
- folds 0～1 门槛：最佳目标 ESS 路径相对最佳旧固定温度路径合并至少改善 `0.20 ft`，任一折不得恶化超过 `0.10 ft`。
- 预计耗时：单井约 40 秒；逐井缓存支持原命令续跑。
- 失败只能否定：冻结旧观测处理下的四条整井目标 ESS 路径，不能否定 PF01 改进观测后再做目标 ESS，也不能否定 PF03 沿井深动态权重。

说明：`P3_PF02a_target_ess_v1` 是不重跑 PF、只在旧四温度中离散选路的快速代理诊断，不是本正式实验。
