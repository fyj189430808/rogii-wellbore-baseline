## 3. 已完成：P3-D00 残差结构诊断

P3-D00 只使用 657 口开发井，影子集井数交集为 0。它是读取真实残差的 oracle 诊断，不生成正式特征，也不是可提交模型。

|---|---:|---:|
| 不修正的 P2-P02 预测 | 10.272146 | 0% |
| 每井一个常数 | 6.675960 | 57.76% |
| 一次函数 | 5.034107 | 75.98% |
| 二次函数 | 4.147006 | 83.70% |

### D00 能证明什么

当前 10.3 基线的大部分误差可以用每口井少量、平滑的系数表示，逐行独立修正不是必要条件。因此，“严格 OOF 预测低维残差系数”值得继续研究。

### D00 不能证明什么

D00 使用了开发井隐藏真值来拟合 oracle 系数。它没有证明测试时合法输入能够预测这些系数，也没有证明 2.35 是可实现的 CV。

## 4. 下一项：P3-D01

实验编号：`P3_D01_pf_observation_weight_audit_v1`

目标是定位 PF 在哪些井段、哪些 GR 条件和哪些路径分歧状态下更容易失效，并判断合法可观测量是否能预先识别这些位置。

D01 必须先做诊断，不直接修改正式模型。至少回答：

1. PF 误差是否集中在 GR 缺失、低辨识度或多峰区域；
2. 多尺度路径之间的分歧是否对应更大的真实误差；
3. 合法可靠性量与误差的关系在不同 fold 是否稳定；
4. 现有固定路径权重是否需要变为按井或按位置变化的权重。

## 5. D01 之后的主路线

```text
P3-PF01  缺失感知、稳健 GR 标定的多随机种子 PF
P3-PF02  固定有效路径数（目标 ESS）的整井加权路径
P3-PF03  分段似然、沿井深动态加权
P3-R01   严格 OOF 预测低维平滑残差系数
```

- 如果旧 sigma 或 GR 标定存在稳定偏差，优先进入 PF01。
- 如果固定温度导致 ESS 随井长或 GR 有效率系统漂移，进入 PF02。
- 如果需要权重沿井深变化，进入 PF03。
- 如果合法井级输入能预测平滑残差系数，进入 R01。

## 6. P3-D01 已完成的事实

- 657 口开发井、3,211,872 个自然隐藏行，影子井重叠 0。
- 新回放与冻结 P2-P01 的 8 个路径字段和 3 个质量量最大差均为 0。
- P2-P02 开发集 RMSE 为 10.272146；最佳固定温度路径为 scale 8，RMSE 10.768667。
- 每井事后最佳温度 oracle RMSE 为 10.252731，相对最佳固定温度有 0.515936 ft 表示余量，但只比 P2-P02 好 0.019415 ft。
- 缺失率和最长 GR 缺口与 PF mean 误差相关很弱，rho 分别为 -0.0136 和 0.0169。
- 当前 sigma 相对 observed-only sigma 的井级中位绝对差为 170.49%。
- 温度 3/5/8/12 的 ESS 与 GR 有效率 rho 为 -0.451～-0.459，五折全部同方向，置换 p=0.000999。
- 按预登记规则 PF01 与 PF02 均获得支持；先执行只改变 sigma 计算的 PF01a，再执行目标 ESS 的 PF02。

任何路线进入正式模型前，都必须使用 657 口开发井、严格 outer-fold 拟合并通过预注册门槛。影子集继续保持关闭，直到用户明确决定进行一次最终确认。

## 7. P3-PF01a 已停止

`P3_PF01a_observed_only_sigma_v1` 只把 `gr_sigma` 改成由真实可见 GR 估计。在 folds 0～1 的 263 口开发井上，旧最佳固定路径 RMSE 为 `10.904921`，新最佳固定路径为 `12.651863`，恶化 `1.746942 ft`；fold 0 和 fold 1 分别恶化 `1.222558 ft` 与 `2.292492 ft`。

因此它没有通过预设门槛，不运行 folds 2～4，也不训练 LightGBM。该结果只否定直接替换 sigma 的实现，下一项为 `P3_PF02a_target_ess_v1`。
