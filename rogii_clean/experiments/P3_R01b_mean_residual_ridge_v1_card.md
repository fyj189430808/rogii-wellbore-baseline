# P3-R01b 实验卡：只预测整井平均残差

实验编号：P3_R01b_mean_residual_ridge_v1

实验名称：严格嵌套 P2-P02 路径的井级平均残差修正

唯一假设：与原始截距 `a0` 和不稳定斜率 `a1` 相比，每口井隐藏段的平均残差更容易由合法井级信息预测。

为什么值得验证：R01a 的两系数 oracle 很强，但 inner folds 1-4 的斜率预测相关全部为负；平均残差才是整井常数修正对应的正确目标。

与当前 R01a 唯一不同之处：目标由 `[a0, a1]` 改为单个 `mean(target_tvt - base_tvt)`，最终只对整条路径加一个常数，不使用斜率。

合法输入：R01a 已生成的严格 inner-OOF/outer0 P2-P02 预测，以及 R01a 简化版的 21 个井级特征。

预测目标：每口井隐藏评价段的平均 P2-P02 残差，单位 ft。

固定 fold：outer fold 0；训练井为 folds 1-4 的 526 口开发井，验证井为 fold 0 的 131 口开发井。

固定评价行：outer fold 0 的 651881 个自然隐藏行。

正对照：未修正的严格嵌套 P2-P02 outer0 路径，RMSE 10.3397936872。

负对照：固定随机种子 20260719，按井打乱训练平均残差目标后重新拟合同一 Ridge。

oracle 诊断：每口井直接加真实平均残差；只报告表示上限，不参与模型选择。

成功门槛：outer0 路径改善至少 0.10 ft；井级自助法差值区间上界小于 0；打乱目标后收益消失；折外目标相关为正。

停止条件：任一核心门槛失败即不补跑其他 outer folds，也不恢复斜率、二次项或控制点。

预计运行时间：1～3 分钟；不训练任何新的 P2-P02 LightGBM。

需要生成的文件：配置、特征清单、参数清单、逐井结果、逐行预测、指标、运行时间和结论。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：固定 21 个简化特征配合 Ridge(alpha=10) 预测单个平均残差的实现。
