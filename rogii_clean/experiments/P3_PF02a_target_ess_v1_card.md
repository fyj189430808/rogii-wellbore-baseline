# P3-PF02a 实验卡：固定目标 ESS 的离散整井选路

- 实验编号：`P3_PF02a_target_ess_v1`
- 唯一假设：不同井不应共用同一温度；只看该井四个无标签 ESS，选择最接近固定目标 `96/128` 的冻结路径，可能比全井统一固定温度更稳。
- 唯一变化：在冻结的 scale 3、5、8、12 四条路径中，每口井离散选择一条。粒子状态、GR sigma、随机种子、路径生成、CV、评价行和 LightGBM 都不变。
- 目标 ESS：`96`。理由是保留约 75% 的 128 条路径，既避免权重严重集中，也不强迫权重接近完全均匀；该值没有使用隐藏 TVT 或误差选择。
- 合法输入：D01 保存的每口井四个 ESS，以及 P2-P01 已冻结的四条路径。
- smoke：固定第一口开发井。
- folds 0～1 门槛：合并 micro RMSE 至少改善 `0.20 ft`，任一折不得恶化超过 `0.10 ft`。
- 停止条件：folds 0～1 未过门槛则不跑 folds 2～4，也不进入 LightGBM。
- 预计耗时：只复制旧缓存并评分，folds 0～1 应为数分钟以内；不重新运行 PF。
- 失败只能否定：`target ESS=96 + 四个离散温度中最近选择` 这一实现，不能否定连续求温度或沿井深动态 ESS。
