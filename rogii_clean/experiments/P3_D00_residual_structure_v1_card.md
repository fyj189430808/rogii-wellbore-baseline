# P3-D00 实验卡：P2-P02 剩余误差结构审计

实验编号：`P3_D00_residual_structure_v1`

实验名称：当前 10.3057 折外残差的低维平滑表示上限

唯一假设：P2-P02 剩余误差的大部分可以由每口井少量低频系数表示，而不是主要由逐行高频噪声组成。

为什么值得验证：若一次残差已低于 7 ft、二次或三次残差低于 5～6 ft，三阶段应把主要资源投入严格折外的井级残差系数预测；若 8 控制点仍高于 8 ft，则应优先改进路径模式和 GR 分支选择。

与当前最佳基线唯一不同之处：不改变基线。本实验只读取已冻结 P2-P02 OOF，对每口开发井做 oracle 残差拟合。

合法输入：P2-P02 OOF 的 `well_id/fold/row_index/md/pred_tvt/target_tvt`；`target_tvt` 只用于明确标注的 oracle。shadow 井在目标列返回前已按 `well_id` 排除。

预测目标：无正式预测目标；诊断残差为 `target_tvt - pred_tvt`。

固定 fold：`balanced_well_5fold_v1`。

固定评价行：非 shadow 开发井的自然隐藏行 `TVT_input.isna()`。

正对照：合成常数、一次、二次、三次和分段线性残差能够被对应基函数恢复。

负对照：基线残差不修正，即 `e_hat=0`。

oracle 诊断：常数、一次、二次、三次、4/8 控制点，分别含锚定与不锚定版本。

成功门槛：一次 oracle `<7 ft` 且二次或三次 oracle `<6 ft`，支持优先进入低维残差学习；8 控制点 `>8 ft` 则支持优先路径分支选择。该门槛只决定路线，不产生正式特征晋级。

停止条件：输出所有预登记表示、逐折和逐井指标后停止，不在本实验训练任何模型。

预计运行时间：读取约 320 万开发行并逐井做小矩阵最小二乘，预计 1～5 分钟。

需要生成的文件：`config.json`、`summary.json`、`per_fold.csv`、`per_well.csv`、`sse_decomposition.csv`、`runtime.json`、`conclusion.md`。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：只能说明 P2-P02 OOF 残差不能被当前固定的低阶多项式和 4/8 个等距分段线性控制点充分表示；不能否定多峰路径、分段权重或其他连续残差表示。
