# P3-D01 实验卡：PF 观测证据与随机路径权重审计

实验编号：`P3_D01_pf_observation_weight_audit_v1`

实验名称：PF 观测证据、似然尺度与固定温度权重审计

唯一假设：当前 PF 将插值 GR 当作独立真实观测，并按整井累计似然使用固定温度，导致路径权重锐度系统性依赖井长、GR 缺失和似然绝对尺度。

为什么值得验证：P2-P01/P02 已证明多随机种子、多温度完整 PF 路径是当前最强新增信息；先查清权重如何失效，才能有依据地实现 PF01 或 PF02。

与当前最佳基线唯一不同之处：没有正式模型变化。本实验只重放冻结 PF 并保存紧凑诊断量，P3B00 的模型、41 列特征、fold、评价行和预测全部不变。

合法输入：

- 当前水平井 `MD/Z/GR/TVT_input`；
- 配对 Typewell `TVT/GR`；
- `balanced_well_5fold_v1`；
- P2-P01 冻结 PF 参数和代码；
- P2-P01 合法四温度路径缓存；
- `P3_shadow_holdout_v1` 的井号和 fold，不读取其目标或误差。

预测目标：无。本实验不训练模型、不生成正式预测。

固定 fold：`balanced_well_5fold_v1`。

固定评价行：657 口开发井中的自然隐藏行 `TVT_input.isna()`；影子井交集必须为 0。

正对照：

- 均匀 128 个似然必须得到 ESS 128、最大权重 1/128、归一化熵 1；
- smoke 井重放的 mean/scale 3/5/8/12 路径必须与 P2-P01 冻结合法缓存逐位一致。

负对照：在井之间固定 seed 打乱合法可靠性统计 1,000 次，真实相关不应由普通随机配对轻易产生。

oracle 诊断：每井在温度 3/5/8/12 中按真实隐藏 TVT 选择最低 RMSE，只用于估计自适应温度的表示余量，禁止成为正式特征或每井规则。

成功门槛：

1. 657 口开发井全部完成，0 口影子井进入目标或误差分析；
2. 所有 ESS 位于 1～128，所有权重和为 1；
3. PF01 证据门槛：缺失/缺口与 PF 均值路径误差 `|Spearman| >= 0.20` 且至少 4/5 折方向一致，或高低缺失四分位路径 RMSE 差至少 0.50 ft 且至少 4/5 折同方向，或两种 sigma 的中位相对差至少 10%；
4. PF02 证据门槛：某温度 ESS 与井长或 GR 有效率 `|Spearman| >= 0.25`、至少 4/5 折同方向、置换比例不高于 0.05，并且 oracle 最佳温度相对最佳全局固定温度至少改善 0.25 ft。

停止条件：

- smoke 路径无法精确复现 P2-P01；
- 合法阶段读取了 TVT、target、error、RMSE、oracle 或 surface；
- 影子井进入 legal task 或评分表；
- 配置、PF 内核、fold、shadow 或 P2-P01 缓存指纹不一致；
- 任一井生成非有限似然且无法由输入错误解释。

预计运行时间：聚焦测试和 smoke 约 2～5 分钟；657 口开发井 8 worker 预计约 45～70 分钟。

需要生成的文件：`config.json`、逐井合法似然缓存、逐井 runtime、`per_well.csv`、相关表、分箱表、温度路径表、`summary.json`、`runtime.json` 和 `conclusion.md`。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：只能否定“用当前这些合法统计解释整井固定温度权重失效”的诊断假设；不能否定 PF、GR、缺失感知更新、多峰路径或低维残差学习。
