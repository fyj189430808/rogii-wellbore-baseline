# P3-R01a：严格嵌套的两系数线性残差

- 实验编号：`P3_R01a_nested_linear_residual_v1`
- 唯一假设：P2-P02 的逐井残差可以用 `r(t)=a0+a1*t` 的两个系数表示，而且测试时合法的井级信息能够预测这两个系数。
- 与基线唯一不同之处：P2-P02 路径生成后，加上 Ridge 预测的逐井常数偏差与线性斜率；不改 PF、不改逐行 LightGBM、不改 CV 和评价行。
- 训练单位：井，一口井一行；不是 321 万逐行样本。
- 系数模型：固定 `StandardScaler + Ridge(alpha=10)`，同时预测 `a0、a1`。
- 外层 fold 0：验证井沿用冻结 P2-P02 fold 0 OOF 路径。
- 严格内层 OOF：外层训练井只来自 folds 1～4；预测某个 inner fold 时，P2-P02 只使用另外三个 inner fold，绝不使用 outer fold 0 或当前 inner held fold。
- 残差坐标：隐藏段 MD 归一化到 0～1；不强制 `a0=0`。
- 合法输入：冻结的 PF/Beam/匹配路径、隐藏 GR 缺失与证据统计、可见前缀 `U=TVT_input+Z` 坡度、P2-P02 预测 `U` 坡度、井眼几何；第一版不加入标签学习的邻井先验。
- 正对照：outer-valid 冻结 P2-P02 路径。
- 负对照：固定 seed 打乱 outer-train 的 `(a0,a1)` 配对后重新训练 Ridge。
- 先评路径自身：不立即塞回主 LightGBM。
- 完整五折通过标准：总体改善至少 0.10 ft；至少 4/5 折改善；井级 bootstrap 95% CI 上界小于 0；打乱目标后收益消失；a0/a1 折外相关在多数折方向一致。
- 当前快速阶段：先完成 outer fold 0 端到端；通过运行机制检查后再扩展其余外折。
- 当前失败只能否定：这组固定井级特征 + `Ridge(alpha=10)` 对两系数线性残差的实现；不能否定低维残差方向。
