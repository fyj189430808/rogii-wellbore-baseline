# 单模 LightGBM 特征实验路线

## 0. 所有实验共同合同

固定不变：

- CV：`spatial_pad_1000_v1`；
- target：`TVT - last_known_TVT`；
- 模型：一个 LightGBM；
- 参数和 1,734 棵树；
- seed 29；
- 自然隐藏评价行；
- 无 early stopping；
- 无模型融合、无 learned trajectory、无 model package；
- 无同井 TVT/surface/contact；
- 每次只改变一个特征组。

每次对照：

- carry-forward；
- 冻结 PF；
- B0 单模 LightGBM；
- B0 + 唯一新特征组。

统一晋级：

- fold 0 改善至少 0.15 ft；
- fold 1 同方向；
- 五折改善至少 0.10 ft；
- 至少 4/5 折同方向；
- 井级 bootstrap 95% CI 上界小于 0；
- P90 不恶化超过 0.5 ft。

## B0：private-safe 单模基线

实验编号：B0

实验名称：冻结单模 LightGBM 基线

唯一假设：当前已理解的合法几何、原始 GR、冻结 PF/Beam 和 Typewell 全局摘要足以建立一个可复现参考点。

为什么值得验证：没有 B0，就无法把以后变化归因到新特征。

与当前最佳基线唯一不同之处：不用历史多模型栈和同井覆盖，改用固定 spatial CV 和一个 LightGBM。

合法输入：当前井 `MD/X/Y/Z/GR/TVT_input`、当前 typewell `TVT/GR`、冻结 PF/Beam、outer-train 安全统计。

预测目标：`TVT - last_known_TVT`。

固定 fold：`spatial_pad_1000_v1`。

固定评价行：`TVT_input.isna()`。

正对照：B0 应至少学到相对 carry 和单条简单几何路径的有效关系。

负对照：target 在井间置乱后，验证性能必须明显崩溃。

oracle 诊断：无；B0 只建立基线。

成功门槛：完整生成相同 OOF、特征列表、配置、逐井和五折指标；固定 seed 重跑差异在预先允许范围内。

停止条件：任何 fold 行数、井数或输入特征不一致立即停止。

预计运行时间：先实测 1～3 井特征构建，再估计 fold 0。

需要生成的文件：`config.json`、`feature_list.json`、`predictions.parquet`、`per_well.csv`、`metrics.json`、`runtime.json`。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：当前 B0 数据管线或固定参数实现。

## F01：前缀结构坐标 U 的多窗口倾角

实验编号：F01

实验名称：可见前缀 `U=TVT_input+Z` 倾角与稳定性

唯一假设：最后可见段的局部构造倾角和稳定性，对隐藏段 TVT 增量有额外信息。

为什么值得验证：只使用当前井可见前缀，成本最低且完全合法。

与 B0 唯一不同之处：新增最近 50/100/200/500/1000 ft 的 robust slope、slope std、短长坡差、曲率、正坡比例，以及倾角外推 delta。

合法输入：可见 `TVT_input`、`Z`、`MD`。

预测目标：固定 target。

固定 fold：固定 primary。

固定评价行：固定自然隐藏段。

正对照：在可见前缀内部早切点回放时，倾角外推应优于 carry。

负对照：井内打乱 MD 顺序后重算同名特征，或把所有 slope 置零。

oracle 诊断：用隐藏真实 U 拟合最佳直线/分段线，只报告信息上限。

成功门槛：统一晋级门槛。

停止条件：伪 holdout 不优于 carry，或 oracle 也没有明显空间，或五折不达门槛。

预计运行时间：短；主要是逐井窗口统计。

需要生成的文件：标准实验 artifact 全套和 `F01_feature_definition.json`。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：这些固定窗口和统计公式。

## F02：GR 缺失与可靠性

实验编号：F02

实验名称：GR 可观测性和插值可靠性

唯一假设：模型需要知道当前 GR/PF 证据何时不可信。

为什么值得验证：现代码把实测 GR 与长缺口插值 GR 基本同等使用。

与 B0 唯一不同之处：新增原始缺失标志、连续缺口长度、距左右实测点距离、50/100/200 ft 有效率、插值跨度、局部 GR MAD/方差和边界缺失。

合法输入：原始 GR 缺失 mask 和可见的 GR 数值。

预测目标、fold、评价行：全部固定。

正对照：冻结 PF 的误差应随缺口长度增加或有效率下降。

负对照：在井内置乱缺失 mask，但保持该井缺失率。

oracle 诊断：逐行知道真值时理想选择 PF/carry 的可靠性上限。

成功门槛：统一晋级门槛。

停止条件：可靠性分箱与 PF 误差无稳定关系，或五折无收益。

预计运行时间：短。

需要生成的文件：标准 artifact 和缺失切片报告。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：当前缺口统计作为 LGBM 特征的实现。

## F03：多尺度 horizontal/typewell GR 对齐

实验编号：F03

实验名称：低频 GR 形态和偏移峰特征

唯一假设：2/5/10/20 ft 的低频 GR 形态比原始逐点差更稳定。

为什么值得验证：直接对应当前 PF 的主要观测信息，但不改变 PF 参数。

与 B0 唯一不同之处：在固定 PF 路径和固定 TVT 偏移网格上新增 robust MAE、NCC、最佳/第二偏移、峰间隔、峰宽和尺度一致性。

合法输入：当前井 GR、当前 typewell TVT/GR、冻结候选路径。

预测目标、fold、评价行：全部固定。

正对照：可见前缀真实 TVT 的对齐分数应优于 ±10/20 ft 错位。

负对照：置乱或循环平移 typewell GR 后判别力应消失。

oracle 诊断：隐藏真实 TVT 下的最佳 offset/scale，只报告上限。

成功门槛：统一晋级门槛。

停止条件：真实前缀位置不能稳定胜过错位，或 oracle 无空间，或五折不达门槛。

预计运行时间：中等；偏移网格和多尺度相关是主要耗时。

需要生成的文件：标准 artifact、前缀对齐正负对照和峰诊断。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：固定尺度、偏移网格和统计方式。

## F04：self-template

实验编号：F04

实验名称：当前井可见前缀的 `GR(TVT_input)` 模板

唯一假设：同一工具、同一井的可见前缀模板比 typewell 幅值更匹配隐藏 GR。

为什么值得验证：完全使用当前井合法前缀，不依赖同井训练副本。

与 B0 唯一不同之处：新增候选 TVT 覆盖标志、self-template 预测 GR、NCC/MAE/最佳偏移/峰间隔，以及 self 与 typewell 得分差。

合法输入：当前井可见前缀的 `TVT_input/GR` 和隐藏段可见 GR。

预测目标、fold、评价行：全部固定。

正对照：前缀前半建模板，应能在后半可见前缀优于错误井模板。

负对照：换成另一口井模板，或打乱 `(TVT_input, GR)` 配对。

oracle 诊断：隐藏真值下评估 self-template 对齐质量和高覆盖子集上限。

成功门槛：统一晋级门槛。

停止条件：覆盖评价行太少、前缀交叉验证失败，或收益只来自极小切片。

预计运行时间：中等。

需要生成的文件：标准 artifact 和每井 coverage 报告。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：当前 bin、插值和相似度实现。

## F05：冻结 PF 的不确定性

实验编号：F05

实验名称：PF seed 分歧、熵和有效粒子统计

唯一假设：PF 内部不确定性可以预测 PF 偏差的大小或方向。

为什么值得验证：不改变 PF，只把已经产生的信息交给唯一 LGBM。

与 B0 唯一不同之处：新增 seed std、q10-q90、likelihood entropy、ESS、top1-top2 loglik gap 和行级分位宽度。

合法输入：固定 seed、粒子和似然产生的诊断量。

预测目标、fold、评价行：全部固定。

正对照：不确定性分位数应与 PF 绝对误差单调相关。

负对照：跨井置乱不确定性列但保留分布。

oracle 诊断：best-of-seeds 和理想 shrinkage，只用于候选池上限。

成功门槛：统一晋级门槛。

停止条件：无误差相关性，随机候选池 oracle 同样好，或五折不达门槛。

预计运行时间：中高；主要耗时是保存和汇总 seed 级路径。

需要生成的文件：标准 artifact、seed 诊断和误差分箱。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：当前不确定性统计的可辨识性。

## F06：可见前缀伪 holdout 统计

实验编号：F06

实验名称：合法候选的 prefix-cut 可靠性

唯一假设：候选在 0.50/0.65/0.75 可见前缀 cuts 上的表现能预测远端可靠性。

为什么值得验证：保留当前高分代码“先自验证”的思想，但不做候选硬选择和输出移动。

与 B0 唯一不同之处：新增 carry、几何、冻结 PF、typewell 候选的 cut RMSE 中位数/方差、gain、margin 和 winner 一致性。

合法输入：可见前缀内部真实 TVT；禁止 contact 候选。

预测目标、fold、评价行：全部固定。

正对照：早 cut 得分应预测下一段可见前缀误差。

负对照：跨井置乱 cut 统计。

oracle 诊断：隐藏 suffix 真值候选排名与 prefix 排名的一致性。

成功门槛：统一晋级门槛。

停止条件：prefix 排名与 suffix 排名无稳定相关，或五折不达门槛。

预计运行时间：中高；每口井要重建多个 cut。

需要生成的文件：标准 artifact 和 prefix/suffix 排名诊断。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：当前 cuts 和候选集作为可靠性特征。

## F07：outer-fold 空间结构特征

实验编号：F07

实验名称：严格 fold 内重建的空间 KNN/局部平面

唯一假设：排除整个验证 pad 后，邻井局部结构仍有可迁移信息。

为什么值得验证：可能提供当前井自身无法观察的长期结构趋势，但泄漏风险和成本最高。

与 B0 唯一不同之处：新增 outer-train KNN/局部平面预测、邻井距离、支持井数、邻域离散度和方向投影。

合法输入：只来自当前 outer-train pads 的训练井。

预测目标、fold、评价行：全部固定。

正对照：在验证井可见前缀上，fold-safe 空间预测应优于全局常数。

负对照：置乱 XY 或井级 surface 值。

oracle 诊断：真实验证 surface/隐藏 U 的完美空间面，仅报告上限。

成功门槛：统一晋级门槛。

停止条件：先审计 surface 是否为目标派生标签；空间支持稀疏、前缀重建失败、置乱也改善或 fold 0 明显恶化时停止。

预计运行时间：最高；五个 outer fold 都要重建空间索引和缓存。

需要生成的文件：标准 artifact、每折空间索引配置、邻距切片和 surface lineage 审计。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：median-XY primary fold 下的当前 KNN/局部平面特征。

## 明确不做

- 不调 LightGBM 参数或树数；
- 不调 PF 参数、scale 或 hold；
- 不换 target；
- 不换 fold；
- 不加 CatBoost、TCN、TabICL 或神经网络；
- 不使用 learned/model package/OOF 预测；
- 不做 stacking 或输出融合；
- 不恢复同井训练 TVT、surface 或 contact；
- 不用一次 fold 0 失败宣布整个信息源无效。
