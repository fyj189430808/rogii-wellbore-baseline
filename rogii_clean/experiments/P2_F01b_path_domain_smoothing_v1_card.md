# P2-F01b 实验卡

实验编号：`P2_F01b_path_domain_smoothing_v1`

实验名称：候选路径采样后在同一 MD 轴平滑的连续 GR 路径

唯一假设：F01 v1 的主要表示问题是水平井 GR 在 MD 轴平滑、Typewell GR 在 TVT 轴平滑；先沿候选 TVT 路径采样 Typewell 原始 GR，再让两条待比较序列都沿 MD 使用相同窗口，能够产生更可辨识的整段 offset 得分面。

为什么值得验证：三井审计显示中位 `|dTVT/dMD|` 约为 `0.03 / 0.21 / 0.03`，同名的平滑窗口在两个坐标轴上并不是同一地层尺度。这个修改直接修正已发现的量纲不一致，也符合《一阶段总结》中“局部实现失败不能否定整段 GR”的结论边界。

与当前 F01 v1 唯一不同之处：

```text
v1：先在 Typewell TVT 轴平滑，再在 center_tvt + offset 处采样
v1b：先在 center_tvt + offset 处采样原始 Typewell GR，再与水平井 GR 一起在 MD 轴平滑
```

PF 中心、offset 网格、50 ft 控制块、五个窗口、支持度、观测代价、初始状态和二阶动态规划全部保持不变。

合法输入：当前井 `MD/GR/TVT_input`；配对 Typewell `TVT/GR`；冻结缓存中的 `row_index/pf_ancc_delta`。

预测目标：诊断阶段生成自然隐藏段的确定性 TVT 路径；合法路径函数不接收隐藏 `TVT`、surface 或任何 oracle 列。

固定 fold：`balanced_well_5fold_v1`。路径不跨井训练，fold 只用于筛查和统一报告。

固定评价行：773 口井的 3,783,989 个自然隐藏行。

固定参数：

- PF 中心：`last_visible_tvt + pf_ancc_delta`；
- offset：`[-40, 40] ft`，步长 `2 ft`；
- MD 控制块：`50 ft`；
- 两条序列共同使用的 MD 平滑窗口：`5/11/21/51/101 ft`；
- 每个相关系数至少 30 个公共有效点，至少 3 个尺度有效；
- 每 50 ft offset 变化：`-4/-2/0/2/4 ft`；
- 相邻变化量之差最多 `2 ft`；
- 虚拟初始状态：`offset=0、change=0`；
- 观测代价和缺失回退公式与 F01 v1 完全相同。

程序正对照：

1. 非周期合成 Typewell、`dTVT/dMD != 1`、满足硬约束的已知 offset 路径，恢复 RMSE 不超过 `2 ft`；
2. 得分面平移等变：前缀中心整体加 `12 ft` 后，新得分 `score'(block, offset)` 必须与原得分 `score(block, offset+12)` 在公共网格上相同，最大 NCC 差不超过 `1e-10`，有效掩码和 pair count 完全一致；
3. 水平井 GR 全部缺失时，最终 offset 最大绝对值不超过 `1e-12 ft`。

真实前缀信号检查：仍给最后最多 1000 ft 的真实 `TVT_input` 中心注入 `12 ft` 半正弦，但不再把“绝对真值必须是 Typewell 最佳位置”当成程序正确性的前提。三井 pooled 上，真实 GR 的恢复 RMSE必须比循环平移 GR 至少好 `2 ft`，才进入 fold 0。

固定 smoke：`000d7d20 / 00bbac68 / 00e12e8b`。它们在 F01b 结果出现前已经固定，覆盖 fold 0/1/2，并可与 F01 v1 严格配对。它们只用于技术与前缀信号筛查，三井隐藏 RMSE不作为正式科学结论。

负对照：

- 隐藏 GR 连同缺失掩码循环平移半段；
- 每个 50 ft 块独立选择最低观测代价，不使用连续约束。

正对照：冻结 PF 中心和未注入的真实可见前缀。

oracle 诊断：全部合法路径先落盘，再单独读取隐藏 TVT，比较 PF、连续路径、循环平移路径和独立块路径；oracle 字段不得进入合法缓存。

fold 0 继续门槛：

- 连续路径相对 PF pooled micro RMSE 至少改善 `0.50 ft`；
- 相对循环平移路径至少改善 `0.50 ft`；
- 相对独立块路径至少改善 `0.50 ft`；
- 优于 PF 的井比例至少 `55%`；
- P90 井 RMSE 相对 PF 恶化不超过 `0.50 ft`；
- 真 offset 落在搜索网格内的比例至少 `90%`。

完整五折成功门槛：

- 连续路径相对 PF pooled micro RMSE 至少改善 `0.50 ft`；
- 至少 `4/5` 折优于 PF，任一折不得恶化超过 `0.50 ft`；
- 相对循环平移路径至少改善 `0.50 ft`；
- 相对独立块路径至少改善 `0.50 ft`；
- 优于 PF 的井比例至少 `55%`；
- P90 井 RMSE 相对 PF 恶化不超过 `0.50 ft`；
- 真 offset 落在搜索网格内的比例至少 `90%`。

停止条件：配置或缓存指纹不一致；行键不一致；合法阶段读取隐藏 TVT/surface；任一程序正对照失败；smoke 的真实前缀未优于循环平移 GR；fold 0 未达到预注册门槛。

预计运行时间：三井 smoke 约 1 分钟；fold 0 约 1 分钟；全量在 4 进程下保守约 2～4 分钟。每口井单独保存，可中断续跑。

需要生成的文件：配置、lineage、逐井 legal score/path、逐井指标、阶段 summary、运行时间和结论。

失败后能否否定整个方向：不能。

失败后只能否定哪一种实现：只能否定“原始 Typewell 按候选路径采样 + 同一 MD 五尺度 Pearson NCC + 当前固定二阶硬约束”。不能否定整段 GR、marker 坐标、其他序列相似度或其他连续状态表示。
