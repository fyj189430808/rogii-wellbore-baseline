## 1. P2-D01：PF 中心多尺度 GR 可辨识性审计

状态：已完成。50/100 ft 独立分块的真实隐藏 GR 与循环打乱负对照几乎没有差异，没有通过预注册门槛。该结果只否定当前局部独立打分，不否定连续整段路径。

目的：在不训练新模型前，判断 Typewell GR 是否真的能在 PF/C01 路径附近识别正确 offset，以及信号在哪些井、哪些尺度和哪些井段有效。

固定设计：

- 中心路径优先使用 C01 中冻结的 PF 路径
- 搜索 offset 以 `[-40, 40] ft` 为主，必要时只做标注清楚的 `[-60, 60] ft` 覆盖诊断
- GR 尺度优先为 `5/11/21/51/101 ft`
- 先按固定 MD 间隔或固定长度块降采样，避免逐行暴力搜索
- 同时记录单尺度与多尺度一致性
- 隐藏真值只用于计算正确 offset 的排名和 oracle 上限，不进入正式特征

必须输出：

- 每井和每块的真实 offset
- 搜索范围覆盖率
- 正确 offset 排名、top-k 命中率
- 最佳峰、次佳峰和峰差
- 多尺度最佳 offset 的离散度
- GR 有效比例和最长缺失段
- 逐井可辨识性与 P2B00 误差的关系
- 是否存在可用合法量定义的两类井

原定直接进入 P2-F01 的条件没有满足。按照《一阶段总结》的主线，先做 P2-S01，获得严格外折的结构中心后，再判断连续 GR 路径是否值得重试。

## 2. P2-S01：严格 outer-fold 空间地层路径

状态：S01、S02、S03 三种最小实现均已完成，均未通过独立路径门槛。

- S01：每井一个代表点的无约束局部平面，`41.9855 ft`。
- S02：dense 点上的跨井局部平面梯度积分，`53.1864 ft`。
- S03：逐控制点单一最近 dense surface，经前缀常数校准，`30.9540 ft`。

这些结果只否定三种具体表示。真实 source 明显优于反转负对照，且近距离井仍有局部信号，因此不能写成“surface 或邻井无效”。根据《一阶段总结》，不再继续堆无条件的小型 surface 变体，转入整段连续 GR 路径。

唯一变化：每折只用 outer-train 井的 formation surface/marker 监督拟合空间结构，再在验证井 XYZ 上生成独立 TVT 路径和不确定度。

硬要求：

- 验证井所有 surface 行完全排除
- 训练井先井级等权或空间网格聚合，不能让长井按行支配
- 所有拟合、尺度和阈值都在 outer fold 内完成
- 同时保存按井主 CV 和旧空间隔离压力测试解释

先测试最简单的局部平面/距离加权；只有明确有信号才增加曲面复杂度。

## 3. P2-F01：在更强结构中心上的连续 offset 路径与前向—后向平滑

状态：v1 已在预注册的三井 smoke 停止，没有运行全量。程序级合成路径能够恢复，但真实前缀注入对照和三井隐藏段都失败；连续路径 `27.2075 ft`，原 PF 中心 `11.7449 ft`。审计没有发现符号、行对齐或动态规划错误。

v1 只能否定当前固定得分表示。审计发现水平井在 MD 轴平滑、Typewell 在 TVT 轴平滑，同一个窗口数字不是同一地层尺度。按照《一阶段总结》“局部打分失败不能否定整段 GR”的约束，随后完成了最小的 `P2-F01b`：沿候选 TVT 列采样参考 GR 后，让两条待比较序列都在同一个 MD 轴平滑；中心、网格、分块和路径约束不变。

P2-F01b 的程序检查与三井前缀信号通过，但固定 fold 0 失败：连续路径 `19.9121 ft`，PF `15.2952 ft`，仅 `11.61%` 的井胜 PF，P90 恶化 `6.90 ft`，因此没有运行全量或 LightGBM。真实 GR 比循环打乱好 `1.68 ft`，说明 GR 信号存在；但真实 offset 在 41 个候选中的块级中位排名只有第 18，top-5 仅 `20.73%`，问题在当前绝对 TVT 得分表示，而不是动态规划漏掉低代价真路径。按路线进入 P2-M01 marker 归一化坐标。

唯一变化：新增一组由多尺度 GR 得分面确定性求出的完整路径及其质量特征，不改变 LightGBM。

目标函数：

```text
GR 不匹配代价
+ offset 一阶变化惩罚
+ offset 二阶曲率惩罚
+ 无证据时回到 PF 中心的惩罚
```

候选输出：

- 前向最优路径
- 后向最优路径
- 前向—后向平均路径
- 平滑 offset
- 局部路径分歧和证据强度
- 缺失 GR 回退标记

P2-D01 没有为局部独立峰值提供支持，因此本项不再照搬它的局部打分。S01～S03 也没有得到稳定优于 carry 的独立 surface 中心，但这不是 F01 的前置失败条件：按《一阶段总结》，F03b 当初的主要问题是恒定 U 中心，而冻结 PF/Beam 中心对真值搜索窗的覆盖率已经很高。因此 F01 直接以冻结 PF/C01 路径为中心，测试带全段连续性约束的最小版本。

## 4. P2-M01：marker 归一化坐标路径

状态：`P2_M01_marker_normalized_coordinate_v1` 已完成固定 fold 0 的 marker 区间排名审计，没有通过预注册门槛，因此不进入 q-state 连续路径实现。

- 149/155 口井可从 outer-train 同指纹、不同井 donor 精确恢复六 marker，模板覆盖率 `96.13%`，withheld marker P90 误差 `0 ft`。
- 14,426/15,236 个块可审计，覆盖率 `94.68%`。
- 错误 top-1 只有 `11.81%` 跨真实 marker 区间；绝大多数别名发生在同一大区间内部。
- oracle 正确区间使 normalized rank 恶化 `0.0028`，合法 PF 区间恶化 `0.0123`；两项井级 bootstrap 均确认没有改善。
- PF 区间与真实区间虽有 `98.27%` 一致率，但区间过宽，平均仍保留约 36/41 个候选，无法提供足够分辨率。

这个结果只否定“六 marker 大区间门控当前 F01b Pearson-NCC 候选”的实现，不否定更细地层坐标、模板专属先验或整段全局配准。

唯一变化：把绝对 TVT 转成相邻 marker 区间内的相对地层坐标，再构造路径或 GR 对齐特征。

硬要求：

- 测试 Typewell marker 必须来自测试期合法来源
- 模板转移必须记录 GR 指纹、匹配置信度和未知模板回退
- 需要额外报告 Typewell 指纹严格分组审计，解释收益是否主要来自重复模板

## 5. 后续扩展条件

只有前四项提供明确证据后，才考虑：

- 多随机种子 PF 的稳定路径摘要
- 近水平段伪隐藏的低阶残差系数
- 井斜、方位和弯曲度对路径门控的精修

任何扩展仍保持单模 LightGBM，并且一次只改变一个信息源。

### 5.1 两类井与重复模板的只读探索证据

这部分是 `[EDA/ORACLE]`，不是正式晋级实验，也不能直接进入特征。

- 773 口井的真实路径终点、低阶形状和 oracle 最优候选家族都没有形成边界清楚的天然两类；两簇轮廓系数只有 `0.205`，三簇反而更高。
- 单次 PF 残差中存在约 158 口“大幅低估井”，终点残差中位数约 `+24.76 ft`，但更像连续误差尾部，不是已经证实的第二种地质井。
- Typewell exact 模板几乎不能区分该故障群；严格 outer-fold 同模板 20 段残差迁移把 PF 从 `14.2433` 恶化到 `14.4134`，五折全部恶化，因此不开展模板中位残差正式实验。
- 隐藏真值事后选择全局两条 PF 残差中心的 oracle 为 `11.1328`；这只证明存在低维多模态空间，不能作为提交特征。
- 测试期合法量中，PF–Beam 终点分歧对 PF 大幅低估群的单变量 AUC 约 `0.726`，随后是终点 dZ、轨迹方向和前缀 U 坡度。后续若登记分型实验，应输入“两条 outer-train 残差中心 + 整段候选分歧”，而不是硬建一个两类分类器。

该方向排在 `P2-P01` 128-seed PF 均值路径之后，因为先减少单次 PF 的随机漂移，才能判断剩余故障群是否仍然存在。

## 6. P2-P01：高分 Notebook 的 128-seed PF 均值路径

状态：完整五折已完成并晋级，成为二阶段当前最佳。

- 固定单模 LightGBM、1,734 棵树、seed 29 不变。
- C01 原 36 列不变，只新增一列 `pf128_mean_delta`，正式共 37 列。
- P2B00：`12.5392278`；P2-P01：`10.9345372`；改善 `1.6046906 ft`。
- 五折：`10.823838 / 10.212162 / 9.934057 / 11.824857 / 11.741139`，相对 P2B00 五折全部改善。
- P90：`18.485520 → 15.342640`；逐井胜率 `69.34%`。

- 新特征五折 gain 排名全部第一，gain 占比约 `29.2%～31.3%`。

合法性：正式特征只读取水平井 `MD/Z/GR/TVT_input` 与 Typewell `TVT/GR`。隐藏 TVT 改写、物理删列、重复运行和并发运行的最大差均为 0；新实现与原 Notebook cell 36/37 在真实井上逐位一致。

收益复核：提升不是由单井或单折撑起，但明显偏向长井和原基线困难井。P2B00 最差 20% 的井贡献约 `83.7%` 净收益；原本最容易的井存在过度修正。因此后续要测试测试期合法的 PF 可靠性和回退特征，不能使用事后误差门控。

下一步：复用当前合法缓存，独立登记多尺度 PF 路径表示。四个 scale 作为一个预先固定的特征组整体进入，不根据五折结果只挑 scale 8；仍先跑 folds 0～1，再决定是否完成五折。之后再单独测试 seed dispersion 等不确定性特征。

## 7. P2-P02：四尺度完整 PF 路径

- 固定 P2-P01 的单个 LightGBM、1,734 棵树、seed 29 和原 37 列不变。
- 只新增 `pf128_scale_3_delta / 5_delta / 8_delta / 12_delta` 四条完整路径，共 41 列。
- 四个尺度作为一个预先固定的特征组整体进入，没有根据五折成绩事后挑某一个尺度。
- P2-P01：`10.9345372`；P2-P02：`10.3057050`；改善 `0.6288322 ft`。
- 五折：`10.170797 / 9.462464 / 9.181974 / 10.875473 / 11.639197`，相对 P2-P01 五折全部改善。
- P90：`15.342640 → 14.360540`；逐井胜率 `61.84%`。
- 按井 bootstrap 95% 区间：`[-1.0300, -0.2437] ft`。
- fold 0 的井内反转负对照为 `10.6836113`，正式特征为 `10.1707967`，说明路径顺序本身提供了信息。
- 四条尺度路径的五折汇总 gain 位列前四，原均值路径第五。

证据边界：该假设是在查看 P2-P01 全五折路径诊断后提出，属于开发证据，不是 untouched holdout。oracle 每井最佳尺度使用隐藏真值，只用于诊断，没有参与正式特征选择。

与《一阶段总结》的关系：结果继续支持“恢复和表达整条 TVT 路径”这条主线；它不依赖公榜同井漏洞，也不意味着任意多尺度特征都会有效。

下一步：独立登记 `P2-P03`，在当前 41 列上只加入 `pf128_seed_std`，测试 128 个固定随机种子之间的分歧能否成为测试期合法的 PF 可靠性特征。

## 8. P2-P03：128 随机种子逐行标准差

状态：folds 0～1 已完成，未通过预注册门槛，按规则停止；没有运行负对照或 folds 2～4。

- P2-P02 原 41 列、固定单模 LightGBM、1,734 棵树和 seed 29 全部不变。
- 只新增一列 `pf128_seed_std`，正式共 42 列。
- fold 0：`10.1762131`，相对 P2-P02 恶化 `0.0054164 ft`。
