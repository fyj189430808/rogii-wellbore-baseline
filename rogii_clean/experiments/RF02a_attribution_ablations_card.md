# RF02a 归因消融实验卡

- 实验编号：RF02a-well / RF02a-local
- 实验名称：井级缺失分布与逐行局部有效率的正交消融
- 唯一假设：RF02a 的收益主要来自井级缺失分布，逐行真实局部有效率只提供较小增量。
- 为什么值得验证：真实与 mask-shift null 都改善 B00，且二者新增特征重要性几乎相同。
- 与 B00 唯一不同之处：well 组只加 2 个井级统计；local 组只加 3 个真实局部有效率。
- 合法输入：当前井完整原始 GR mask 与 MD，不使用隐藏 TVT。
- 预测目标：`TVT - last_visible_TVT`，保持不变。
- 固定 fold：`spatial_pad_1000_v1`。
- 固定评价行：`TVT_input.isna()`。
- 正对照：真实位置的 well/local 组。
- 负对照：对应组使用井内循环平移 mask，但保留真实 B00 `gr_raw/gr_missing`。
- oracle 诊断：不使用。
- 成功门槛：每个真实组沿用统一晋级门槛；真实相对对应 null 的 paired bootstrap 单独报告。
- 停止条件：fold1 不同向则不跑该组完整五折；完成两组后不再穷举四个零重要性 gap 几何列。
- 预计运行时间：每个版本首次缓存约 1 分钟，每折约 1.5 分钟。
- 需要生成的文件：四个独立配置/产物，以及真实-null/B00 配对比较。
- 失败后能否否定整个方向：不能。
- 失败后只能否定哪一种实现：这两个固定特征子集在当前 LGBM 中的实现。
